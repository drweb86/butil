## Karagdagang mga tuntunin para sa edisyon ng China

Nalalapat ang mga karagdagang tuntuning ito kapag ginagamit mo ang edisyon ng China ng BUtil. Hindi nililimitahan ng mga ito ang paglalaan ng CC0 sa pampublikong domain ng pinagmulan ng software. Kung magkasalungat ang mga ito sa paraan ng paggamit mo ng naka-install na app sa device mo, ang mga tuntuning ito ang mamamahala sa paggamit na iyon.

**Pangalan ng software:** BUtil

**Tagapagpaunlad:** Siarhei Kuchuk

Ito ay lokal na kasangkapan sa backup, synchronization, at file na pinapatakbo mo sa sarili mong device. Libre ito. Walang in-app purchase, subscription, advertising, o virtual na pera.

Dapat mong basahin at sang-ayunan ang patakaran sa pribasiya at ang lisensyang ito bago gamitin ang app. Kung hindi ka sumasang-ayon, permanenteng binubura ng app ang mga lokal na nakaimbak na gawain, setting, at password, pagkatapos ay nagsasara. Hindi binubura ang mga file sa mga folder na pinili mo. Maaari mong i-uninstall ang app sa mga setting ng sistema.

Maaari mong bawiin ang pagsang-ayon anumang oras gamit ang button sa screen na ito. Ganito rin ang ginagawa ng pagbawi: permanenteng binubura nito ang mga lokal na nakaimbak na gawain, setting, at password, pagkatapos ay isinasara ang app. Hindi binubura ang mga file sa mga folder na pinili mo. Maaari mong i-install muli ang app sa ibang pagkakataon.

Gamitin ang software alinsunod lamang sa mga batas ng Republika ng Bayan ng Tsina. Ikaw ang responsable kung sino ang makakaabot sa server na ibinabahagi mo, aling mga folder ang pipiliin mo, at ang lakas ng password. Huwag gamitin ang software para sa ilegal na gawain.

Hindi nagpapatakbo ang developer ng mga account ng user, cloud storage, mga bayad na online na serbisyo, o chat ng serbisyo sa customer para sa app na ito.

Pinapanatili ng mga open-source na bahagi ng ikatlong partido ang sarili nilang mga lisensya. Hindi muling nililisensya ng CC0 ang mga bahaging iyon.

Hindi isinusuko ng CC0 ang mga trademark at patent. Tinutukoy ng pangalang BUtil ang aplikasyong ito.

Ibinibigay ang software nang ganito, nang walang garantiya, hanggang sa pinahihintulutan ng batas.

Kung menor de edad ka, dapat basahin at sang-ayunan ng magulang o tagapag-alaga ang lisensyang ito bago gamitin.

Ang mga batas ng Republika ng Bayan ng Tsina ang namamahala sa mga karagdagang tuntuning ito. Maaaring ihain ang mga alitan sa karampatang hukuman ng bayan alinsunod sa batas.

Walang malware, advertising SDK, o nakatagong pagkolekta ng datos ng developer ang edisyong ito. Hindi ipinapadala ng app ang mga file mo o mga password sa developer.

Upang huminto sa paggamit ng software, bawiin ang pahintulot dito o i-uninstall ang app sa mga setting ng sistema.

Para sa mga tanong, gamitin ang listahan ng tindahan kung saan mo ini-install ang app.
