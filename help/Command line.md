# UI

| Platform | Example | Description |
| --- | --- | --- |
| Windows (Installer) | `butil-ui.Desktop.exe LaunchTask "Task=My task name"` | Launches specified task. |
| Windows (Store) | `%LOCALAPPDATA%\Microsoft\WindowsApps\SiarheiKuchuk.BUtil.UI.exe LaunchTask "Task=My task name"` | Launches specified task. |
| Linux | `/usr/local/butil/butil-ui.Desktop LaunchTask "Task=My task name"` | Launches specified task. |

# Console

| Platform | Example | Description |
| --- | --- | --- |
| Windows (Installer) | `butilc.exe "Task=My task name"` | Executes the task. |
| Windows (Store) | `%LOCALAPPDATA%\Microsoft\WindowsApps\SiarheiKuchuk.BUtil.Console.exe "Task=My task name"` | Executes the task. |
| Linux | `/usr/local/butil/butilc "Task=My task name"` | Executes the task. |
| Windows (Installer) | `butilc.exe "Task=My task name" Shutdown` | Executes the task and shutdowns the PC. |
| Windows (Store) | `%LOCALAPPDATA%\Microsoft\WindowsApps\SiarheiKuchuk.BUtil.Console.exe "Task=My task name" Shutdown` | Executes the task and shutdowns the PC. |
| Linux | `/usr/local/butil/butilc "Task=My task name" Shutdown` | Executes the task and shutdowns the PC. |
| Windows (Installer) | `butilc.exe "Task=My task name" LogOff` | Executes the task and ends the user session. |
| Windows (Store) | `%LOCALAPPDATA%\Microsoft\WindowsApps\SiarheiKuchuk.BUtil.Console.exe "Task=My task name" LogOff` | Executes the task and ends the user session. |
| Linux | `/usr/local/butil/butilc "Task=My task name" LogOff` | Executes the task and ends the user session. |
| Windows (Installer) | `butilc.exe "Task=My task name" Reboot` | Executes the task and reboots the PC. |
| Windows (Store) | `%LOCALAPPDATA%\Microsoft\WindowsApps\SiarheiKuchuk.BUtil.Console.exe "Task=My task name" Reboot` | Executes the task and reboots the PC. |
| Linux | `/usr/local/butil/butilc "Task=My task name" Reboot` | Executes the task and reboots the PC. |
