# سیاست حریم خصوصی

آخرین به‌روزرسانی: ۲۵ سپتامبر ۲۰۲۶

**BUtil** by Siarhei Kuchuk

نام برنامه: BUtil
نام توسعه‌دهنده: Siarhei Kuchuk

BUtil از فایل‌ها در این رایانه نسخه پشتیبان می‌گیرد، آن‌ها را همگام می‌کند و بازیابی می‌کند. همچنین می‌تواند رسانه وارد کند، پوشه‌ای را به اشتراک بگذارد یا فایل‌ها را به سروری که تنظیم می‌کنید بارگذاری کند. حساب توسعه‌دهنده نمی‌سازد. توسعه‌دهنده سروری ندارد که فایل‌ها، گذرواژه‌ها یا داده‌های استفاده شما را دریافت کند.

## داده‌هایی که توسعه‌دهنده جمع نمی‌کند

این برنامه تبلیغ، تحلیل، گزارش خرابی یا SDK ردیابی ندارد. توسعه‌دهنده داده‌های شخصی را جمع، فروخته یا هم‌رسانی نمی‌کند.

## داده‌های ذخیره‌شده روی رایانه شما

### وظیفه‌ها و تنظیمات

تعریف وظیفه‌ها فقط روی این رایانه ذخیره می‌شود. یک وظیفه می‌تواند مسیر پوشه‌ها، زمان‌بندی، تنظیمات ذخیره‌سازی و گذرواژه یا توکن‌هایی را که وارد می‌کنید در بر بگیرد. گذرواژه‌ها و رازهای ذخیره‌سازی پیش از ذخیره روی این رایانه رمزنگاری می‌شوند و فقط روی این رایانه خوانده می‌شوند. این مقدارها برای توسعه‌دهنده فرستاده نمی‌شوند.

- وظیفه‌های Windows: `%AppData%\BUtil Backup Tasks`
- وظیفه‌های Linux: `~/.config/BUtil Backup Tasks`
- تنظیمات Windows (شامل زمینه و زبانی که آخرین بار برای مجوز یا حریم خصوصی انتخاب شده): `%AppData%\BUtil\Settings\v1`
- تنظیمات Linux: `~/.config/BUtil/Settings/v1`
- وضعیت وظیفه‌های Windows: `%AppData%\BUtil\States`
- وضعیت وظیفه‌های Linux: `~/.config/BUtil/States`
- وضعیت وارد کردن رسانه در Windows: `%AppData%\BUtil Backup Tasks - States`
- وضعیت وارد کردن رسانه در Linux: `~/.config/BUtil Backup Tasks - States`

### فایل‌هایی که انتخاب می‌کنید

پشتیبان‌گیری، همگام‌سازی، بازیابی و وارد کردن، پوشه‌هایی را که انتخاب می‌کنید می‌خوانند و می‌نویسند. این فایل‌ها روی این رایانه یا در مقصد ذخیره‌سازی که تنظیم می‌کنید می‌مانند. برنامه آن‌ها را برای توسعه‌دهنده بارگذاری نمی‌کند.

### گزارش‌ها

گزارش‌های تشخیصی فقط روی این رایانه نوشته می‌شوند:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

این فایل‌ها به جایی فرستاده نمی‌شوند.

برای ذخیره داده‌های شما از سرور توسعه‌دهنده استفاده نمی‌شود.

## استفاده از شبکه

### مقصدهایی که تنظیم می‌کنید

وقتی وظیفه‌ای اجرا می‌شود، برنامه فقط به جایی وصل می‌شود که تعیین کرده‌اید. این می‌تواند یک پوشه محلی یا سروری باشد که وارد می‌کنید: FTP، FTPS، SFTP، WebDAV، SMB، NFS، ذخیره‌سازی سازگار با S3 یا Azure Blob Storage. نام فایل‌ها، محتوای فایل‌ها و اطلاعات ورود که وارد کرده‌اید به آن سرور فرستاده می‌شود تا وظیفه بتواند اجرا شود. هر یک از این خدمات سیاست حریم خصوصی خود را دارد. توسعه‌دهنده این ترافیک را دریافت نمی‌کند.

BUtil Server می‌تواند روی این رایانه گوش دهد تا کارخواه BUtil که تنظیم می‌کنید بتواند فایل بفرستد. این ترافیک میان رایانه‌هایی که تنظیم می‌کنید می‌ماند.

### بررسی به‌روزرسانی

نسخه‌های خارج از Store ممکن است آخرین انتشار GitHub را درخواست کنند:

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) یک درخواست معمولی HTTPS دریافت می‌کند (نشانی IP، user-agent، زمان). توسعه‌دهنده این ترافیک را دریافت نمی‌کند.

نصب‌ها از Microsoft Store از این بررسی استفاده نمی‌کنند؛ به‌روزرسانی‌ها را Store می‌رساند.

## زمان‌بندی

در Windows می‌توانید وظیفه‌ای را هنگام ورود یا طبق زمان‌بندی هفتگی اجرا کنید. برنامه آن را در زمان‌بند وظیفه Windows با نامی که با `BUtil` آغاز می‌شود ثبت می‌کند. این کار فقط این برنامه را روی رایانه شما اجرا می‌کند.
