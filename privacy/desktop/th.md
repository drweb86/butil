# นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 25 กันยายน 2026

**BUtil** by Siarhei Kuchuk

ชื่อแอปพลิเคชัน: BUtil
ชื่อผู้พัฒนา: Siarhei Kuchuk

BUtil สำรองข้อมูล ซิงโครไนซ์ และกู้คืนไฟล์บนคอมพิวเตอร์เครื่องนี้ นอกจากนี้ยังนำเข้าสื่อ แชร์โฟลเดอร์ หรืออัปโหลดไฟล์ไปยังเซิร์ฟเวอร์ที่คุณตั้งค่าได้ แอปไม่สร้างบัญชีผู้พัฒนา ผู้พัฒนาไม่ได้ดำเนินเซิร์ฟเวอร์ที่รับไฟล์ รหัสผ่าน หรือข้อมูลการใช้งานของคุณ

## ข้อมูลที่ผู้พัฒนาไม่เก็บ

แอปไม่มีโฆษณา การวิเคราะห์ รายงานข้อขัดข้อง หรือ SDK ติดตาม ผู้พัฒนาไม่เก็บ ขาย หรือแบ่งปันข้อมูลส่วนบุคคล

## ข้อมูลที่จัดเก็บบนคอมพิวเตอร์ของคุณ

### งานและการตั้งค่า

คำจำกัดความของงานจัดเก็บไว้บนคอมพิวเตอร์เครื่องนี้เท่านั้น งานอาจมีเส้นทางโฟลเดอร์ กำหนดการ การตั้งค่าที่เก็บ และรหัสผ่านหรือโทเค็นที่คุณพิมพ์ รหัสผ่านและความลับของที่เก็บจะถูกเข้ารหัสบนคอมพิวเตอร์เครื่องนี้ก่อนบันทึก และอ่านได้เฉพาะบนคอมพิวเตอร์เครื่องนี้ ค่าเหล่านี้ไม่ถูกอัปโหลดให้ผู้พัฒนา

- งาน Windows: `%AppData%\BUtil Backup Tasks`
- งาน Linux: `~/.config/BUtil Backup Tasks`
- การตั้งค่า Windows (รวมถึงธีมและภาษาที่เลือกครั้งล่าสุดสำหรับสัญญาอนุญาตหรือความเป็นส่วนตัว): `%AppData%\BUtil\Settings\v1`
- การตั้งค่า Linux: `~/.config/BUtil/Settings/v1`
- สถานะงาน Windows: `%AppData%\BUtil\States`
- สถานะงาน Linux: `~/.config/BUtil/States`
- สถานะการนำเข้าสื่อ Windows: `%AppData%\BUtil Backup Tasks - States`
- สถานะการนำเข้าสื่อ Linux: `~/.config/BUtil Backup Tasks - States`

### ไฟล์ที่คุณเลือก

การสำรอง การซิงโครไนซ์ การกู้คืน และการนำเข้าจะอ่านและเขียนโฟลเดอร์ที่คุณเลือก ไฟล์เหล่านั้นอยู่บนคอมพิวเตอร์เครื่องนี้หรือที่ปลายทางการจัดเก็บที่คุณตั้งค่า แอปไม่อัปโหลดให้ผู้พัฒนา

### บันทึก

บันทึกการวินิจฉัยเขียนเฉพาะบนคอมพิวเตอร์เครื่องนี้:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

ไฟล์เหล่านั้นไม่ถูกส่งไปที่ใด

ไม่มีเซิร์ฟเวอร์ของผู้พัฒนาที่ใช้จัดเก็บข้อมูลของคุณ

## การใช้เครือข่าย

### ปลายทางที่คุณตั้งค่า

เมื่องานทำงาน แอปจะเชื่อมต่อเฉพาะสถานที่ที่คุณกำหนด อาจเป็นโฟลเดอร์ในเครื่องหรือเซิร์ฟเวอร์ที่คุณป้อน: FTP, FTPS, SFTP, WebDAV, SMB, NFS, ที่เก็บที่เข้ากันได้กับ S3 หรือ Azure Blob Storage ชื่อไฟล์ เนื้อหาไฟล์ และข้อมูลรับรองที่คุณป้อนจะถูกส่งไปยังเซิร์ฟเวอร์นั้นเพื่อให้งานทำงานได้ แต่ละบริการมีนโยบายความเป็นส่วนตัวของตนเอง ผู้พัฒนาไม่ได้รับทราฟฟิกนั้น

BUtil Server สามารถรอรับการเชื่อมต่อบนคอมพิวเตอร์เครื่องนี้ เพื่อให้ไคลเอ็นต์ BUtil ที่คุณตั้งค่าส่งไฟล์ได้ ทราฟฟิกนั้นอยู่ระหว่างคอมพิวเตอร์ที่คุณตั้งค่า

`https://api.github.com/repos/drweb86/butil/releases/latest`

## กำหนดการ

บน Windows คุณสามารถให้งานทำงานเมื่อลงชื่อเข้าใช้หรือตามกำหนดการรายสัปดาห์ แอปลงทะเบียนสิ่งนี้ในตัวจัดกำหนดการงานของ Windows ด้วยชื่อที่ขึ้นต้นด้วย `BUtil` สิ่งนี้เพียงเปิดแอปนี้บนคอมพิวเตอร์ของคุณ
