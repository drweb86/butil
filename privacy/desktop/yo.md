# Ìlànà ìpamọ́

Ìmúdójúìwọ̀n tó kẹ́yìn: 25 Oṣù Kẹ̀sán 2026

**BUtil** by Siarhei Kuchuk

Orúkọ ohun èlò: BUtil
Orúkọ olùdàgbàsókè: Siarhei Kuchuk

BUtil ń ṣe àfipamọ́, ń ṣe ìbámu, ó sì ń dá àwọn fáìlì padà lórí kọ̀m̀pútà yìí. Ó tún lè gbé mídíà wọlé, pín fóldà, tàbí gbé àwọn fáìlì lọ sí sáfà tí o ṣètò. Kò dá àkántì olùdàgbàsókè. Olùdàgbàsókè kò ṣiṣẹ́ sáfà kan tí ó ń gba àwọn fáìlì rẹ, ọ̀rọ̀ aṣínà, tàbí dátà ìlò.

## Dátà tí olùdàgbàsókè kò kójọ

Ohun èlò kò ní ìpolówó, ìtúpalẹ̀, ìjábọ̀ ìkùnà, tàbí SDK ìtọpinpin. Olùdàgbàsókè kò kójọ, ta, tàbí pín dátà ti ara ẹni.

## Dátà tí a fi pamọ́ lórí kọ̀m̀pútà rẹ

### Àwọn iṣẹ́ àti ètò

Àwọn ìtumọ̀ iṣẹ́ wà lórí kọ̀m̀pútà yìí nìkan. Iṣẹ́ kan lè ní àwọn ọ̀nà fóldà, ètò àkókò, ètò ìpamọ́, àti àwọn ọ̀rọ̀ aṣínà tàbí tókìn tí o tẹ̀. A ń parí àwọn ọ̀rọ̀ aṣínà àti àṣírí ìpamọ́ lórí kọ̀m̀pútà yìí kí a tó fi wọn pamọ́, a sì lè kà wọn lórí kọ̀m̀pútà yìí nìkan. A kò fi àwọn iye wọ̀nyí ránṣẹ́ sí olùdàgbàsókè.

- Àwọn iṣẹ́ Windows: `%AppData%\BUtil Backup Tasks`
- Àwọn iṣẹ́ Linux: `~/.config/BUtil Backup Tasks`
- Ètò Windows (pẹ̀lú àwọ̀ àti èdè tí a yan kẹ́yìn fún ìwé-àṣẹ tàbí ìpamọ́): `%AppData%\BUtil\Settings\v1`
- Ètò Linux: `~/.config/BUtil/Settings/v1`
- Ipò iṣẹ́ Windows: `%AppData%\BUtil\States`
- Ipò iṣẹ́ Linux: `~/.config/BUtil/States`
- Ipò ìgbéwọlé mídíà Windows: `%AppData%\BUtil Backup Tasks - States`
- Ipò ìgbéwọlé mídíà Linux: `~/.config/BUtil Backup Tasks - States`

### Àwọn fáìlì tí o yàn

Àfipamọ́, ìbámu, ìdàpadà, àti ìgbéwọlé ń kà ó sì ń kọ àwọn fóldà tí o yàn. Àwọn fáìlì náà dúró lórí kọ̀m̀pútà yìí tàbí níbi ìpamọ́ tí o ṣètò. Ohun èlò kò gbé wọn lọ sí olùdàgbàsókè.

### Àwọn àkọsílẹ̀

Àwọn àkọsílẹ̀ àyẹ̀wò ni a kọ lórí kọ̀m̀pútà yìí nìkan:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

A kò fi àwọn fáìlì náà ránṣẹ́ sí ibikíbi.

Kò sí sáfà olùdàgbàsókè tí a ń lò láti fi dátà rẹ pamọ́.

## Lílo nẹ́tíwọ́ọ̀kì

### Àwọn ibi tí o ṣètò

Nígbà tí iṣẹ́ ń ṣiṣẹ́, ohun èlò ń sopọ̀ sí ibi tí o yan nìkan. Ó lè jẹ́ fóldà abẹ́lé tàbí sáfà tí o tẹ̀: FTP, FTPS, SFTP, WebDAV, SMB, NFS, ìpamọ́ tí ó bá S3 mu, tàbí Azure Blob Storage. Orúkọ fáìlì, àkóónú, àti àwọn ẹ̀rí tí o tẹ̀ ni a fi ránṣẹ́ sí sáfà náà kí iṣẹ́ lè ṣiṣẹ́. Iṣẹ́ kọ̀ọ̀kan ní ìlànà ìpamọ́ tirẹ̀. Olùdàgbàsókè kò gba ìrìn-àjò náà.

BUtil Server lè gbọ́ lórí kọ̀m̀pútà yìí kí oníbàárà BUtil tí o ṣètò lè fi fáìlì ránṣẹ́. Ìrìn-àjò náà dúró láàárín àwọn kọ̀m̀pútà tí o ṣètò.

### Àyẹ̀wò ìmúdójúìwọ̀n

Àwọn ìkọ́ tí kì í ṣe Store lè béèrè ìjáde GitHub tuntun:

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) ń gba ìbéèrè HTTPS déédé (àdírẹ́sì IP, user-agent, àkókò). Olùdàgbàsókè kò gba ìrìn-àjò náà.

Àwọn fífi sórí ẹ̀rọ láti Microsoft Store kò lo àyẹ̀wò yìí; Store ni ó ń gbé ìmúdójúìwọ̀n.

### Àwọn ìjápọ̀ tí o ṣí

Ohun èlò lè ṣí àwọn ojú-ìwé wọ̀nyí nínú aṣàwákiri ẹ̀rọ. Àwọn ojú-òpó wẹ́ẹ̀bù náà ní àwọn ìlànà ìpamọ́ tiwọn:

- Ojú-ìwé ilé iṣẹ́: [github.com/drweb86/butil](https://github.com/drweb86/butil)
- Ìjáde tuntun: [github.com/drweb86/butil/releases/latest](https://github.com/drweb86/butil/releases/latest)
- Ìrànlọ́wọ́ àpẹẹrẹ fáìlì: [learn.microsoft.com file globbing](https://learn.microsoft.com/en-us/dotnet/core/extensions/file-globbing#pattern-formats)
- Ìrànlọ́wọ́ àpẹẹrẹ ọjọ́: [learn.microsoft.com custom date and time format strings](https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings)
- Orísun àwọn àmì: [github.com/drweb86/butil Icons](https://github.com/drweb86/butil/blob/master/help/Icons.md)

A ń fi ìwé-àṣẹ àti ìlànà ìpamọ́ yìí hàn nínú ohun èlò. A kò ṣí wọn gẹ́gẹ́ bí ojú-ìwé wẹ́ẹ̀bù.

## Ètò àkókò

Lórí Windows o lè ṣiṣẹ́ iṣẹ́ nígbà tí o bá wọlé tàbí ní ètò ọ̀sẹ̀-ọ̀sẹ̀. Ohun èlò ń forúkọ sílẹ̀ nínú Windows Task Scheduler pẹ̀lú orúkọ tí ó bẹ̀rẹ̀ pẹ̀lú `BUtil`. Èyí ń bẹ̀rẹ̀ ohun èlò yìí lórí kọ̀m̀pútà rẹ nìkan.

GitHub ń ṣe ìbéèrè àyẹ̀wò ìmúdójúìwọ̀n àti àwọn ojú-ìwé tí o ṣí, gẹ́gẹ́ bí a ṣe sọ lókè. Microsoft Store ń ṣe àwọn fífi sórí ẹ̀rọ àti ìmúdójúìwọ̀n Store. Àwọn olùpèsè ìpamọ́ tí o ṣètò ń ṣe àwọn fáìlì àti ẹ̀rí tí iṣẹ́ fi ránṣẹ́ sí wọn. Olùdàgbàsókè kò gba ìrìn-àjò náà.
