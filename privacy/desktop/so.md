# Siyaasadda asturnaanta

Cusbooneysiintii ugu dambeysay: 25 Sebtembar 2026

**BUtil** by Siarhei Kuchuk

Magaca barnaamijka: BUtil
Magaca horumariyaha: Siarhei Kuchuk

BUtil wuxuu kaydiyaa, wuxuu iswaafajiyaa, wuxuuna soo celiyaa faylasha kumbuyuutarkan. Waxa kale oo uu soo dejin karaa warbaahin, wuxuu wadaagi karaa galka, ama wuxuu faylasha u diri karaa server aad dejisay. Ma abuuro akoon horumariye. Horumariyuhu ma maamulo server helaya faylashaada, furaha sirta ah, ama xogta isticmaalka.

## Xogta uu horumariyuhu ururin

Barnaamijku ma laha xayeysiis, falanqayn, warbixin burbur, ama SDK raadraac. Horumariyuhu ma ururiyo, ma iibiyo, mana wadaago xogta shakhsi ahaaneed.

## Xogta lagu kaydiyo kumbuyuutarkaaga

### Hawlaha iyo dejinta

Qeexitaannada hawlaha waxaa lagu kaydiyaa kumbuyuutarkan oo keliya. Hawshu waxay ku jiri kartaa wadooyinka galka, jadwal, dejinta kaydinta, iyo furayaasha sirta ah ama token-yada aad qorto. Furayaasha sirta ah iyo sirta kaydinta waa la qarxiyaa kumbuyuutarkan ka hor inta aan la kaydin, waxaana lagu akhrin karaa kumbuyuutarkan oo keliya. Qiimayaashan lama dirto horumariyaha.

- Hawlaha Windows: `%AppData%\BUtil Backup Tasks`
- Hawlaha Linux: `~/.config/BUtil Backup Tasks`
- Dejinta Windows (oo ay ku jiraan mawduuca iyo luqadda ugu dambeysay ee loo doortay shatiga ama asturnaanta): `%AppData%\BUtil\Settings\v1`
- Dejinta Linux: `~/.config/BUtil/Settings/v1`
- Xaaladda hawlaha Windows: `%AppData%\BUtil\States`
- Xaaladda hawlaha Linux: `~/.config/BUtil/States`
- Xaaladda soo dejinta warbaahinta Windows: `%AppData%\BUtil Backup Tasks - States`
- Xaaladda soo dejinta warbaahinta Linux: `~/.config/BUtil Backup Tasks - States`

### Faylasha aad doorato

Kaydinta, iswaafajinta, soo celinta, iyo soo dejintu waxay akhriyaan oo qoraan galalka aad doorato. Faylashaas waxay ku sii nagaadaan kumbuyuutarkan ama kaydinta aad dejisay. Barnaamijku uma diro horumariyaha.

### Diiwaannada

Diiwaannada baaritaanka waxaa lagu qoraa kumbuyuutarkan oo keliya:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

Faylashaas meelna looma diro.

Server horumariye laguma kaydiyo xogtaada.

## Isticmaalka shabakadda

### Meelaha aad dejiso

Marka hawshu socoto, barnaamijku wuxuu ku xirmaa oo keliya meesha aad dejisay. Taasi waxay noqon kartaa gal maxalli ah ama server aad geliso: FTP, FTPS, SFTP, WebDAV, SMB, NFS, kaydin la jaan qaadi karta S3, ama Azure Blob Storage. Magacyada faylasha, waxa ku jira, iyo aqoonsiyada aad gelisay waxaa loo diraa serverkaas si hawshu u socoto. Adeeg kasta wuxuu leeyahay siyaasad asturnaaneed oo u gaar ah. Horumariyuhu ma helo taraafikadaas.

BUtil Server wuxuu dhageysan karaa kumbuyuutarkan si macmiilka BUtil ee aad dejisay uu u diro faylal. Taraafikadaas waxay ku sii nagaanaysaa kumbuyuutarrada aad dejisay.

## Jadwalka

Windows waxaad hawsha ku socodsiin kartaa markaad gasho ama jadwal toddobaadle ah. Barnaamijku wuxuu ku diiwaangeliyaa Windows Task Scheduler magac ku bilaabma `BUtil`. Tani waxay kaliya ka bilowdaa barnaamijkan kumbuyuutarkaaga.
