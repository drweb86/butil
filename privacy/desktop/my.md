# ကိုယ်ရေးအချက်အလက် မူဝါဒ

နောက်ဆုံးအပ်ဒိတ်: ၂၅ စက်တင်ဘာ ၂၀၂၆

**BUtil** by Siarhei Kuchuk

အက်ပ်အမည်: BUtil
ဖန်တီးသူအမည်: Siarhei Kuchuk

BUtil သည် ဤကွန်ပျူတာပေါ်ရှိ ဖိုင်များကို အရန်သိမ်းသည်၊ တစ်ပြိုင်တည်းလုပ်သည်၊ ပြန်ယူသည်။ မီဒီယာတင်သွင်းခြင်း၊ ဖိုလ်ဒါမျှဝေခြင်း သို့မဟုတ် သင်သတ်မှတ်ထားသော ဆာဗာသို့ ဖိုင်တင်ခြင်းလည်း လုပ်နိုင်သည်။ ဖန်တီးသူအကောင့် မဖွင့်ပါ။ ဖန်တီးသူသည် သင့်ဖိုင်များ၊ စကားဝှက်များ သို့မဟုတ် အသုံးပြုမှုဒေတာကို လက်ခံသော ဆာဗာ မလုပ်ဆောင်ပါ။

## ဖန်တီးသူ မစုဆောင်းသော ဒေတာ

အက်ပ်တွင် ကြော်ငြာ၊ ခွဲခြမ်းစိတ်ဖြာမှု၊ ပျက်စီးမှုအစီရင်ခံစာ သို့မဟုတ် ခြေရာခံ SDK မပါပါ။ ဖန်တီးသူသည် ကိုယ်ရေးဒေတာကို မစုဆောင်း၊ မရောင်း၊ မမျှဝေပါ။

## သင့်ကွန်ပျူတာတွင် သိမ်းထားသော ဒေတာ

### အလုပ်များနှင့် ဆက်တင်များ

အလုပ်အဓိပ္ပာယ်ဖွင့်ဆိုချက်များကို ဤကွန်ပျူတာတွင်သာ သိမ်းသည်။ အလုပ်တစ်ခုတွင် ဖိုလ်ဒါလမ်းကြောင်း၊ အချိန်ဇယား၊ သိုလှောင်မှုဆက်တင်နှင့် သင်ရိုက်သော စကားဝှက် သို့မဟုတ် တိုကင်များ ပါနိုင်သည်။ စကားဝှက်နှင့် သိုလှောင်မှုလျှို့ဝှက်ချက်များကို မသိမ်းမီ ဤကွန်ပျူတာတွင် ကုဒ်ဝှက်ပြီး ဤကွန်ပျူတာတွင်သာ ဖတ်နိုင်သည်။ ထိုတန်ဖိုးများကို ဖန်တီးသူထံ မပို့ပါ။

- Windows အလုပ်များ: `%AppData%\BUtil Backup Tasks`
- Linux အလုပ်များ: `~/.config/BUtil Backup Tasks`
- Windows ဆက်တင်များ (အပြင်အဆင်နှင့် လိုင်စင် သို့မဟုတ် ကိုယ်ရေးအချက်အလက်အတွက် နောက်ဆုံးရွေးထားသော ဘာသာစကား အပါအဝင်): `%AppData%\BUtil\Settings\v1`
- Linux ဆက်တင်များ: `~/.config/BUtil/Settings/v1`
- Windows အလုပ်အခြေအနေ: `%AppData%\BUtil\States`
- Linux အလုပ်အခြေအနေ: `~/.config/BUtil/States`
- Windows မီဒီယာတင်သွင်းမှု အခြေအနေ: `%AppData%\BUtil Backup Tasks - States`
- Linux မီဒီယာတင်သွင်းမှု အခြေအနေ: `~/.config/BUtil Backup Tasks - States`

### သင်ရွေးသော ဖိုင်များ

အရန်သိမ်းခြင်း၊ တစ်ပြိုင်တည်းလုပ်ခြင်း၊ ပြန်ယူခြင်းနှင့် တင်သွင်းခြင်းသည် သင်ရွေးသော ဖိုလ်ဒါများကို ဖတ်ပြီး ရေးသည်။ ထိုဖိုင်များသည် ဤကွန်ပျူတာ သို့မဟုတ် သင်သတ်မှတ်သော သိုလှောင်ရာတွင် ကျန်သည်။ အက်ပ်သည် ဖန်တီးသူထံ မပို့ပါ။

### မှတ်တမ်းများ

စစ်ဆေးရေးမှတ်တမ်းများကို ဤကွန်ပျူတာတွင်သာ ရေးသည်။

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

ထိုဖိုင်များကို ဘယ်ကိုမှ မပို့ပါ။

သင့်ဒေတာသိမ်းရန် ဖန်တီးသူဆာဗာကို မသုံးပါ။

## ကွန်ရက်အသုံးပြုမှု

### သင်သတ်မှတ်သော နေရာများ

အလုပ်တစ်ခု လုပ်သောအခါ အက်ပ်သည် သင်သတ်မှတ်သော နေရာသို့သာ ချိတ်ဆက်သည်။ ဒေသခံဖိုလ်ဒါ သို့မဟုတ် သင်ထည့်သော ဆာဗာ ဖြစ်နိုင်သည်။ FTP၊ FTPS၊ SFTP၊ WebDAV၊ SMB၊ NFS၊ S3 နှင့် ကိုက်ညီသော သိုလှောင်မှု သို့မဟုတ် Azure Blob Storage။ ဖိုင်အမည်၊ ဖိုင်အကြောင်းအရာနှင့် သင်ထည့်သော အထောက်အထားများကို အလုပ်လုပ်နိုင်ရန် ထိုဆာဗာသို့ ပို့သည်။ ဝန်ဆောင်မှုတိုင်းတွင် ကိုယ်ပိုင် ကိုယ်ရေးမူဝါဒ ရှိသည်။ ဖန်တီးသူသည် ထိုအသွားအလာကို မရပါ။

BUtil Server သည် သင်သတ်မှတ်သော BUtil ကလိုင်းယင့် ဖိုင်ပို့နိုင်ရန် ဤကွန်ပျူတာတွင် နားထောင်နိုင်သည်။ ထိုအသွားအလာသည် သင်ပြင်ဆင်သော ကွန်ပျူတာများကြားတွင်သာ ရှိသည်။

### အပ်ဒိတ်စစ်ဆေးခြင်း

Store မဟုတ်သော တည်ဆောက်မှုများသည် နောက်ဆုံး GitHub ထုတ်ဝေမှုကို တောင်းနိုင်သည်။

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) သည် ပုံမှန် HTTPS တောင်းဆိုမှု (IP လိပ်စာ၊ user-agent၊ အချိန်) ရသည်။ ဖန်တီးသူသည် ထိုအသွားအလာကို မရပါ။

Microsoft Store မှ တပ်ဆင်မှုများသည် ဤစစ်ဆေးမှုကို မသုံးပါ။ အပ်ဒိတ်များကို Store ပို့သည်။

### သင်ဖွင့်သော လင့်များ

အက်ပ်သည် ဤစာမျက်နှာများကို စနစ်ဘရောက်ဇာတွင် ဖွင့်နိုင်သည်။ ထိုဆိုက်များတွင် ကိုယ်ပိုင် ကိုယ်ရေးမူဝါဒ ရှိသည်။

- ပရောဂျက်ပင်မစာမျက်နှာ: [github.com/drweb86/butil](https://github.com/drweb86/butil)
- နောက်ဆုံးထုတ်ဝေမှု: [github.com/drweb86/butil/releases/latest](https://github.com/drweb86/butil/releases/latest)
- ဖိုင်ပုံစံ အကူအညီ: [learn.microsoft.com file globbing](https://learn.microsoft.com/en-us/dotnet/core/extensions/file-globbing#pattern-formats)
- ရက်စွဲပုံစံ အကူအညီ: [learn.microsoft.com custom date and time format strings](https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings)
- အိုင်ကွန်ရင်းမြစ်: [github.com/drweb86/butil Icons](https://github.com/drweb86/butil/blob/master/help/Icons.md)

လိုင်စင်နှင့် ဤကိုယ်ရေးမူဝါဒကို အက်ပ်အတွင်း ပြသည်။ ဝဘ်စာမျက်နှာအဖြစ် မဖွင့်ပါ။

## အချိန်ဇယား

Windows တွင် အကောင့်ဝင်ချိန် သို့မဟုတ် အပတ်စဉ် အချိန်ဇယားဖြင့် အလုပ်လုပ်နိုင်သည်။ အက်ပ်သည် ၎င်းကို `BUtil` ဖြင့် စသော အမည်ဖြင့် Windows Task Scheduler တွင် မှတ်ပုံတင်သည်။ ၎င်းသည် ဤအက်ပ်ကို သင့်ကွန်ပျူတာတွင်သာ ဖွင့်သည်။

## ကလေးများ

အက်ပ်သည် အရန်သိမ်းခြင်းနှင့် ဖိုင်တစ်ပြိုင်တည်းလုပ်ခြင်း ကိရိယာဖြစ်သည်။ အသက် ၁၃ နှစ်အောက် ကလေးများအတွက် မဟုတ်ပါ။

## တတိယပါတီများ

GitHub သည် အပ်ဒိတ်စစ်ဆေးမှု တောင်းဆိုချက်နှင့် သင်ဖွင့်သော စာမျက်နှာများကို အထက်တွင် ဖော်ပြထားသည့်အတိုင်း ဆောင်ရွက်သည်။ Microsoft Store သည် Store တပ်ဆင်မှုနှင့် အပ်ဒိတ်များကို ဆောင်ရွက်သည်။ သင်သတ်မှတ်သော သိုလှောင်မှုပေးသူများသည် အလုပ်ပို့သော ဖိုင်များနှင့် အထောက်အထားများကို ဆောင်ရွက်သည်။ ဖန်တီးသူသည် ထိုအသွားအလာကို မရပါ။

## ပြောင်းလဲမှုများ
