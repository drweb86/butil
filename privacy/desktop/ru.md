# Политика конфиденциальности

Последнее обновление: 25 сентября 2026 г.

**BUtil** by Siarhei Kuchuk

Имя приложения: BUtil
Имя разработчика: Siarhei Kuchuk

BUtil создаёт резервные копии, синхронизирует и восстанавливает файлы на этом компьютере. Программа также может импортировать медиафайлы, открывать общий доступ к папке или отправлять файлы на сервер, который вы указываете. Она не создаёт учётную запись разработчика. Разработчик не использует сервер, который получает ваши файлы, пароли или данные об использовании.

## Данные, которые разработчик не собирает

В приложении нет рекламы, аналитики, отправки отчётов о сбоях и SDK отслеживания. Разработчик не собирает, не продаёт и не передаёт персональные данные.

## Данные, хранящиеся на вашем компьютере

### Задачи и параметры

Описания задач хранятся только на этом компьютере. В задачу могут входить пути к папкам, расписание, параметры хранилища, а также пароли или токены, которые вы вводите. Пароли и секреты хранилища шифруются на этом компьютере перед сохранением, и прочитать их можно только на этом компьютере. Эти значения не отправляются разработчику.

- Задачи Windows: `%AppData%\BUtil Backup Tasks`
- Задачи Linux: `~/.config/BUtil Backup Tasks`
- Параметры Windows (включая тему и язык, последний выбранный для лицензии или политики конфиденциальности): `%AppData%\BUtil\Settings\v1`
- Параметры Linux: `~/.config/BUtil/Settings/v1`
- Состояние задач Windows: `%AppData%\BUtil\States`
- Состояние задач Linux: `~/.config/BUtil/States`
- Состояние импорта медиа Windows: `%AppData%\BUtil Backup Tasks - States`
- Состояние импорта медиа Linux: `~/.config/BUtil Backup Tasks - States`

### Файлы, которые вы выбираете

Резервное копирование, синхронизация, восстановление и импорт читают и записывают выбранные вами папки. Эти файлы остаются на этом компьютере или в хранилище, которое вы настраиваете. Приложение не отправляет их разработчику.

### Журналы

Диагностические журналы записываются только на этом компьютере:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

Эти файлы никуда не отправляются.

Сервер разработчика не используется для хранения ваших данных.

## Использование сети

### Места, которые вы настраиваете

Когда задача выполняется, приложение подключается только к указанному вами месту. Это может быть локальная папка или сервер, который вы вводите: FTP, FTPS, SFTP, WebDAV, SMB, NFS, хранилище, совместимое с S3, или Azure Blob Storage. Имена файлов, содержимое файлов и введённые вами учётные данные отправляются на этот сервер, чтобы задача могла выполниться. У каждой такой службы своя политика конфиденциальности. Разработчик этот трафик не получает.

BUtil Server может ожидать подключения на этом компьютере, чтобы настроенный вами клиент BUtil мог отправлять файлы. Этот трафик остаётся между компьютерами, которые вы настроили.

### Проверка обновлений

Сборки не из Store могут запрашивать последний выпуск на GitHub:

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) получает обычный запрос HTTPS (IP-адрес, user-agent, время). Разработчик этот трафик не получает.

Установки из Microsoft Store эту проверку не используют; обновления доставляет Store.

### Ссылки, которые вы открываете

Приложение может открывать эти страницы в системном браузере. У этих сайтов свои политики конфиденциальности:

- Страница проекта: [github.com/drweb86/butil](https://github.com/drweb86/butil)
- Последний выпуск: [github.com/drweb86/butil/releases/latest](https://github.com/drweb86/butil/releases/latest)
- Справка по шаблонам файлов: [learn.microsoft.com file globbing](https://learn.microsoft.com/en-us/dotnet/core/extensions/file-globbing#pattern-formats)
- Справка по формату даты: [learn.microsoft.com custom date and time format strings](https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings)
- Авторы значков: [github.com/drweb86/butil Icons](https://github.com/drweb86/butil/blob/master/help/Icons.md)

Лицензия и эта политика конфиденциальности показываются внутри приложения. Они не открываются как веб-страницы.

## Расписание

В Windows задачу можно запускать при входе в систему или по недельному расписанию. Приложение регистрирует это в Планировщике заданий Windows под именем, которое начинается с `BUtil`. Это только запускает это приложение на вашем компьютере.

## Дети

Приложение предназначено для резервного копирования и синхронизации файлов. Оно не ориентировано на детей младше 13 лет.

## Третьи стороны

GitHub обрабатывает запрос проверки обновлений и страницы, которые вы открываете, как описано выше. Microsoft Store обрабатывает установки и обновления из Store. Поставщики хранилищ, которых вы настраиваете, обрабатывают файлы и учётные данные, которые задача им отправляет. Разработчик этот трафик не получает.

## Изменения

Обновления этой политики будут публиковаться в этом файле в репозитории проекта.
