# গোপনীয়তা নীতি

সর্বশেষ আপডেট: ২৫ সেপ্টেম্বর ২০২৬

**BUtil** by Siarhei Kuchuk

অ্যাপের নাম: BUtil
ডেভেলপারের নাম: Siarhei Kuchuk

BUtil এই কম্পিউটারে ফাইল ব্যাকআপ করে, সিঙ্ক করে এবং ফিরিয়ে আনে। এটি মিডিয়া আমদানি করতে, ফোল্ডার শেয়ার করতে, বা আপনার সেট করা সার্ভারে ফাইল আপলোড করতে পারে। এটি ডেভেলপার অ্যাকাউন্ট তৈরি করে না। ডেভেলপার এমন কোনো সার্ভার চালান না যা আপনার ফাইল, পাসওয়ার্ড বা ব্যবহারের তথ্য গ্রহণ করে।

## ডেভেলপার যে তথ্য সংগ্রহ করেন না

অ্যাপে বিজ্ঞাপন, বিশ্লেষণ, ক্র্যাশ রিপোর্ট বা ট্র্যাকিং SDK নেই। ডেভেলপার ব্যক্তিগত তথ্য সংগ্রহ, বিক্রি বা শেয়ার করেন না।

## আপনার কম্পিউটারে সংরক্ষিত তথ্য

### কাজ ও সেটিংস

কাজের সংজ্ঞা শুধু এই কম্পিউটারে থাকে। একটি কাজে ফোল্ডারের পথ, সময়সূচি, স্টোরেজ সেটিংস এবং আপনার লেখা পাসওয়ার্ড বা টোকেন থাকতে পারে। পাসওয়ার্ড ও স্টোরেজ গোপন তথ্য সংরক্ষণের আগে এই কম্পিউটারে এনক্রিপ্ট হয় এবং শুধু এই কম্পিউটারে পড়া যায়। এই মানগুলো ডেভেলপারের কাছে যায় না।

- Windows কাজ: `%AppData%\BUtil Backup Tasks`
- Linux কাজ: `~/.config/BUtil Backup Tasks`
- Windows সেটিংস (থিম এবং লাইসেন্স বা গোপনীয়তার জন্য শেষ নির্বাচিত ভাষা সহ): `%AppData%\BUtil\Settings\v1`
- Linux সেটিংস: `~/.config/BUtil/Settings/v1`
- Windows কাজের অবস্থা: `%AppData%\BUtil\States`
- Linux কাজের অবস্থা: `~/.config/BUtil/States`
- Windows মিডিয়া আমদানির অবস্থা: `%AppData%\BUtil Backup Tasks - States`
- Linux মিডিয়া আমদানির অবস্থা: `~/.config/BUtil Backup Tasks - States`

### আপনার বেছে নেওয়া ফাইল

ব্যাকআপ, সিঙ্ক, পুনরুদ্ধার ও আমদানি আপনার নির্বাচিত ফোল্ডার পড়ে ও লেখে। সেই ফাইল এই কম্পিউটারে বা আপনার সেট করা স্টোরেজে থাকে। অ্যাপ সেগুলো ডেভেলপারের কাছে পাঠায় না।

### লগ

ডায়াগনস্টিক লগ শুধু এই কম্পিউটারে লেখা হয়:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

সেই ফাইল কোথাও পাঠানো হয় না।

আপনার তথ্য রাখতে ডেভেলপারের কোনো সার্ভার ব্যবহার হয় না।

## নেটওয়ার্ক ব্যবহার

### আপনার সেট করা গন্তব্য

কোনো কাজ চললে অ্যাপ শুধু আপনার নির্ধারিত জায়গায় যুক্ত হয়। সেটি স্থানীয় ফোল্ডার বা আপনার দেওয়া সার্ভার হতে পারে: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-সামঞ্জস্যপূর্ণ স্টোরেজ বা Azure Blob Storage। ফাইলের নাম, বিষয়বস্তু এবং আপনার দেওয়া পরিচয়পত্র সেই সার্ভারে যায় যাতে কাজ চলতে পারে। প্রতিটি সেবার নিজস্ব গোপনীয়তা নীতি আছে। ডেভেলপার এই ট্রাফিক পান না।

BUtil Server এই কম্পিউটারে শুনতে পারে যাতে আপনার সেট করা BUtil ক্লায়েন্ট ফাইল পাঠাতে পারে। সেই ট্রাফিক আপনার সেট করা কম্পিউটারগুলোর মধ্যে থাকে।

### আপডেট পরীক্ষা

Store-এর বাইরের বিল্ড সর্বশেষ GitHub রিলিজ চাইতে পারে:

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) একটি সাধারণ HTTPS অনুরোধ পায় (IP ঠিকানা, user-agent, সময়)। ডেভেলপার এই ট্রাফিক পান না।

Microsoft Store থেকে ইনস্টল এই পরীক্ষা ব্যবহার করে না; আপডেট Store দেয়।

### আপনার খোলা লিঙ্ক

অ্যাপ সিস্টেম ব্রাউজারে এই পৃষ্ঠাগুলো খুলতে পারে। সেই সাইটের নিজস্ব গোপনীয়তা নীতি আছে:

- প্রকল্পের হোমপেজ: [github.com/drweb86/butil](https://github.com/drweb86/butil)
- সর্বশেষ রিলিজ: [github.com/drweb86/butil/releases/latest](https://github.com/drweb86/butil/releases/latest)
- ফাইল প্যাটার্ন সহায়তা: [learn.microsoft.com file globbing](https://learn.microsoft.com/en-us/dotnet/core/extensions/file-globbing#pattern-formats)
- তারিখের ফরম্যাট সহায়তা: [learn.microsoft.com custom date and time format strings](https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings)
- আইকনের উৎস: [github.com/drweb86/butil Icons](https://github.com/drweb86/butil/blob/master/help/Icons.md)

লাইসেন্স ও এই গোপনীয়তা নীতি অ্যাপের ভিতরে দেখানো হয়। এগুলো ওয়েব পৃষ্ঠা হিসেবে খোলে না।

## সময়সূচি

Windows-এ আপনি সাইন-ইন করার সময় বা সাপ্তাহিক সময়সূচিতে কাজ চালাতে পারেন। অ্যাপ এটি Windows Task Scheduler-এ এমন নামে নিবন্ধন করে যা `BUtil` দিয়ে শুরু হয়। এতে শুধু এই অ্যাপ আপনার কম্পিউটারে চালু হয়।

## তৃতীয় পক্ষ

GitHub আপডেট পরীক্ষার অনুরোধ এবং আপনার খোলা পৃষ্ঠা উপরের বর্ণনা অনুযায়ী প্রক্রিয়া করে। Microsoft Store, Store ইনস্টল ও আপডেট প্রক্রিয়া করে। আপনার সেট করা স্টোরেজ প্রদানকারীরা কাজ যে ফাইল ও পরিচয়পত্র পাঠায় তা প্রক্রিয়া করে। ডেভেলপার এই ট্রাফিক পান না।
