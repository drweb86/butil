# गोपनीयता नीति

अन्तिम अद्यावधिक: २५ सेप्टेम्बर २०२६

**BUtil** by Siarhei Kuchuk

अनुप्रयोगको नाम: BUtil
विकासकर्ताको नाम: Siarhei Kuchuk

BUtil यस कम्प्युटरमा फाइलहरूको जगेडा गर्छ, समक्रमण गर्छ र पुनर्स्थापना गर्छ। यसले मिडिया आयात गर्न, फोल्डर साझा गर्न वा तपाईंले सेट गरेको सर्भरमा फाइल अपलोड गर्न सक्छ। यसले विकासकर्ता खाता बनाउँदैन। विकासकर्ताले तपाईंका फाइल, पासवर्ड वा प्रयोग डेटा प्राप्त गर्ने सर्भर चलाउँदैनन्।

## विकासकर्ताले सङ्कलन नगर्ने डेटा

एपमा विज्ञापन, विश्लेषण, क्र्यास रिपोर्ट वा ट्र्याकिङ SDK छैन। विकासकर्ताले व्यक्तिगत डेटा सङ्कलन, बिक्री वा साझेदारी गर्दैनन्।

## तपाईंको कम्प्युटरमा भण्डारण गरिएको डेटा

### कार्य र सेटिङ

कार्यका परिभाषा यस कम्प्युटरमा मात्र भण्डारण हुन्छन्। कार्यमा फोल्डर मार्ग, तालिका, भण्डारण सेटिङ र तपाईंले टाइप गरेका पासवर्ड वा टोकन हुन सक्छन्। पासवर्ड र भण्डारण गोप्य जानकारी सुरक्षित गर्नुअघि यस कम्प्युटरमा एन्क्रिप्ट हुन्छन् र यस कम्प्युटरमा मात्र पढ्न सकिन्छ। ती मान विकासकर्तालाई पठाइँदैनन्।

- Windows कार्य: `%AppData%\BUtil Backup Tasks`
- Linux कार्य: `~/.config/BUtil Backup Tasks`
- Windows सेटिङ (थिम र इजाजतपत्र वा गोपनीयताका लागि अन्तिम छानिएको भाषा सहित): `%AppData%\BUtil\Settings\v1`
- Linux सेटिङ: `~/.config/BUtil/Settings/v1`
- Windows कार्यको अवस्था: `%AppData%\BUtil\States`
- Linux कार्यको अवस्था: `~/.config/BUtil/States`
- Windows मिडिया आयातको अवस्था: `%AppData%\BUtil Backup Tasks - States`
- Linux मिडिया आयातको अवस्था: `~/.config/BUtil Backup Tasks - States`

### तपाईंले छानेका फाइल

जगेडा, समक्रमण, पुनर्स्थापना र आयातले तपाईंले छानेका फोल्डर पढ्छन् र लेख्छन्। ती फाइल यस कम्प्युटरमा वा तपाईंले सेट गरेको भण्डारणमा रहन्छन्। एपले ती विकासकर्तालाई पठाउँदैन।

### लग

निदान लग यस कम्प्युटरमा मात्र लेखिन्छन्:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

ती फाइल कतै पठाइँदैनन्।

तपाईंको डेटा भण्डारण गर्न विकासकर्ताको सर्भर प्रयोग हुँदैन।

## सञ्जाल प्रयोग

### तपाईंले सेट गरेका गन्तव्य

कार्य चल्दा एप तपाईंले तोकेको ठाउँमा मात्र जोडिन्छ। त्यो स्थानीय फोल्डर वा तपाईंले हालेको सर्भर हुन सक्छ: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-मिल्दो भण्डारण वा Azure Blob Storage। फाइल नाम, सामग्री र तपाईंले हालेका प्रमाणपत्र कार्य चल्न त्यस सर्भरमा पठाइन्छन्। प्रत्येक सेवाको आफ्नै गोपनीयता नीति छ। विकासकर्ताले यो ट्राफिक पाउँदैनन्।

BUtil Server यस कम्प्युटरमा सुन्न सक्छ ताकि तपाईंले सेट गरेको BUtil क्लाइन्टले फाइल पठाउन सकोस्। त्यो ट्राफिक तपाईंले सेट गरेका कम्प्युटरहरूबीच रहन्छ।

## तालिका

Windows मा तपाईं साइन-इन गर्दा वा साप्ताहिक तालिकामा कार्य चलाउन सक्नुहुन्छ। एपले यसलाई Windows Task Scheduler मा `BUtil` बाट सुरु हुने नाममा दर्ता गर्छ। यसले यो एप तपाईंको कम्प्युटरमा मात्र सुरु गर्छ।
