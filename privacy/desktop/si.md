# පෞද්ගලිකත්ව ප්‍රතිපත්තිය

අවසන් යාවත්කාලීනය: 2026 සැප්තැම්බර් 25

**BUtil** by Siarhei Kuchuk

යෙදුමේ නම: BUtil
සංවර්ධකයාගේ නම: Siarhei Kuchuk

BUtil මෙම පරිගණකයේ ගොනු උපස්ථ කරයි, සමමුහූර්ත කරයි සහ ප්‍රතිසාධනය කරයි. එය මාධ්‍ය ආයාත කළ හැක, ෆෝල්ඩරයක් බෙදා ගත හැක, නැතහොත් ඔබ සකස් කළ සේවාදායකයකට ගොනු උඩුගත කළ හැක. එය සංවර්ධක ගිණුමක් සාදන්නේ නැත. සංවර්ධකයා ඔබේ ගොනු, මුරපද හෝ භාවිත දත්ත ලබන සේවාදායකයක් ක්‍රියාත්මක නොකරයි.

## සංවර්ධකයා එකතු නොකරන දත්ත

යෙදුමේ දැන්වීම්, විශ්ලේෂණ, බිඳවැටීම් වාර්තා හෝ ලුහුබැඳීමේ SDK නැත. සංවර්ධකයා පුද්ගලික දත්ත එකතු නොකරයි, විකුණන්නේ නැත හෝ බෙදා නොගනී.

## ඔබේ පරිගණකයේ ගබඩා වන දත්ත

### කාර්ය සහ සැකසුම්

කාර්ය අර්ථ දැක්වීම් මෙම පරිගණකයේ පමණක් ගබඩා වේ. කාර්යයකට ෆෝල්ඩර් මාර්ග, කාලසටහන, ගබඩා සැකසුම් සහ ඔබ ටයිප් කළ මුරපද හෝ ටෝකන ඇතුළත් විය හැක. මුරපද සහ ගබඩා රහස් සුරැකීමට පෙර මෙම පරිගණකයේ සංකේතනය වන අතර මෙම පරිගණකයේ පමණක් කියවිය හැක. එම අගයන් සංවර්ධකයාට යවනු නොලැබේ.

- Windows කාර්ය: `%AppData%\BUtil Backup Tasks`
- Linux කාර්ය: `~/.config/BUtil Backup Tasks`
- Windows සැකසුම් (තේමාව සහ බලපත්‍රය හෝ පෞද්ගලිකත්වය සඳහා අවසන් වරට තෝරාගත් භාෂාව ඇතුළුව): `%AppData%\BUtil\Settings\v1`
- Linux සැකසුම්: `~/.config/BUtil/Settings/v1`
- Windows කාර්ය තත්ත්වය: `%AppData%\BUtil\States`
- Linux කාර්ය තත්ත්වය: `~/.config/BUtil/States`
- Windows මාධ්‍ය ආයාත තත්ත්වය: `%AppData%\BUtil Backup Tasks - States`
- Linux මාධ්‍ය ආයාත තත්ත්වය: `~/.config/BUtil Backup Tasks - States`

### ඔබ තෝරන ගොනු

උපස්ථය, සමමුහූර්තය, ප්‍රතිසාධනය සහ ආයාතය ඔබ තෝරන ෆෝල්ඩර කියවා ලියයි. එම ගොනු මෙම පරිගණකයේ හෝ ඔබ සකස් කළ ගබඩාවේ පවතී. යෙදුම ඒවා සංවර්ධකයාට උඩුගත නොකරයි.

### ලොග

රෝග විනිශ්චය ලොග මෙම පරිගණකයේ පමණක් ලියනු ලැබේ:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

එම ගොනු කොතැනකටවත් යවනු නොලැබේ.

ඔබේ දත්ත ගබඩා කිරීමට සංවර්ධක සේවාදායකයක් භාවිත නොවේ.

## ජාල භාවිතය

### ඔබ සකස් කරන ගමනාන්ත

කාර්යයක් ධාවනය වන විට යෙදුම ඔබ නියම කළ ස්ථානයට පමණක් සම්බන්ධ වේ. එය දේශීය ෆෝල්ඩරයක් හෝ ඔබ ඇතුළත් කළ සේවාදායකයක් විය හැක: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-අනුකූල ගබඩාව හෝ Azure Blob Storage. ගොනු නම්, අන්තර්ගතය සහ ඔබ ඇතුළත් කළ අක්තපත්‍ර කාර්යය ධාවනය වීමට එම සේවාදායකයට යවනු ලැබේ. එක් එක් සේවාවට තමන්ගේම පෞද්ගලිකත්ව ප්‍රතිපත්තියක් ඇත. සංවර්ධකයා එම ගමනාගමනය ලබන්නේ නැත.

BUtil Server මෙම පරිගණකයේ සවන් දිය හැක, එවිට ඔබ සකස් කළ BUtil සේවාදායකයාට ගොනු යැවිය හැක. එම ගමනාගමනය ඔබ සකස් කළ පරිගණක අතර පවතී.
