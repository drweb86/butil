# Құпиялылық саясаты

Соңғы жаңарту: 2026 жылғы 25 қыркүйек

**BUtil** by Siarhei Kuchuk

Қолданба атауы: BUtil
Әзірлеушінің аты: Siarhei Kuchuk

BUtil осы компьютердегі файлдардың сақтық көшірмесін жасайды, оларды синхрондайды және қалпына келтіреді. Ол медианы импорттай алады, қалтаны бөлісе алады немесе файлдарды сіз баптаған серверге жүктей алады. Әзірлеуші тіркелгісін жасамайды. Әзірлеуші файлдарыңызды, құпиясөздеріңізді немесе пайдалану деректеріңізді қабылдайтын серверді жүргізбейді.

## Әзірлеуші жинамайтын деректер

Қолданбада жарнама, талдау, іркіліс есептері немесе бақылау SDK жоқ. Әзірлеуші жеке деректерді жинамайды, сатпайды және бөліспейді.

## Компьютеріңізде сақталатын деректер

### Тапсырмалар мен параметрлер

Тапсырма анықтамалары тек осы компьютерде сақталады. Тапсырма қалта жолдарын, кестені, сақтау параметрлерін және сіз енгізген құпиясөздерді немесе токендерді қамтуы мүмкін. Құпиясөздер мен сақтау құпиялары сақталмас бұрын осы компьютерде шифрланады және тек осы компьютерде оқылады. Бұл мәндер әзірлеушіге жіберілмейді.

- Windows тапсырмалары: `%AppData%\BUtil Backup Tasks`
- Linux тапсырмалары: `~/.config/BUtil Backup Tasks`
- Windows параметрлері (тақырыпты және лицензия немесе құпиялылық үшін соңғы таңдалған тілді қоса): `%AppData%\BUtil\Settings\v1`
- Linux параметрлері: `~/.config/BUtil/Settings/v1`
- Windows тапсырма күйі: `%AppData%\BUtil\States`
- Linux тапсырма күйі: `~/.config/BUtil/States`
- Windows медиа импортының күйі: `%AppData%\BUtil Backup Tasks - States`
- Linux медиа импортының күйі: `~/.config/BUtil Backup Tasks - States`

### Сіз таңдаған файлдар

Сақтық көшірме, синхрондау, қалпына келтіру және импорт сіз таңдаған қалталарды оқиды және жазады. Бұл файлдар осы компьютерде немесе сіз баптаған сақтау орнында қалады. Қолданба оларды әзірлеушіге жүктемейді.

### Журналдар

Диагностикалық журналдар тек осы компьютерге жазылады:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

Бұл файлдар ешқайда жіберілмейді.

Деректеріңізді сақтау үшін әзірлеуші сервері пайдаланылмайды.

## Желіні пайдалану

### Сіз баптайтын орындар

Тапсырма орындалғанда қолданба тек сіз көрсеткен жерге қосылады. Бұл жергілікті қалта немесе сіз енгізген сервер болуы мүмкін: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-үйлесімді сақтау немесе Azure Blob Storage. Файл атаулары, файл мазмұны және енгізген тіркелгі деректері тапсырма орындалуы үшін сол серверге жіберіледі. Бұл қызметтердің әрқайсысының өз құпиялылық саясаты бар. Әзірлеуші бұл трафикті алмайды.

BUtil Server сіз баптаған BUtil клиенті файл жібере алуы үшін осы компьютерде тыңдай алады. Бұл трафик сіз баптаған компьютерлер арасында қалады.

### Жаңартуды тексеру

Store-дан тыс жинақтар GitHub-тағы соңғы шығарылымды сұрауы мүмкін:

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) кәдімгі HTTPS сұрауын алады (IP мекенжайы, user-agent, уақыт). Әзірлеуші бұл трафикті алмайды.

Microsoft Store орнатулары бұл тексеруді пайдаланбайды; жаңартуларды Store жеткізеді.

Қолданба бұл беттерді жүйе браузерінде аша алады. Бұл сайттардың өз құпиялылық саясаты бар:

- Соңғы шығарылым: [github.com/drweb86/butil/releases/latest](https://github.com/drweb86/butil/releases/latest)

## Кесте

Windows жүйесінде тапсырманы кірген кезде немесе апталық кесте бойынша іске қоса аласыз. Қолданба оны Windows тапсырма жоспарлаушысында `BUtil` деп басталатын атаумен тіркейді. Бұл тек осы қолданбаны компьютеріңізде іске қосады.
