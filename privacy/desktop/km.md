# គោលការណ៍ឯកជនភាព

ធ្វើបច្ចុប្បន្នភាពចុងក្រោយ៖ 25 កញ្ញា 2026

**BUtil** by Siarhei Kuchuk

ឈ្មោះកម្មវិធី៖ BUtil
ឈ្មោះអ្នកអភិវឌ្ឍន៍៖ Siarhei Kuchuk

BUtil ធ្វើការបម្រុងទុក ធ្វើសមកាលកម្ម និងស្ដារឯកសារនៅលើកុំព្យូទ័រនេះ។ វាក៏អាចនាំចូលមេឌៀ ចែករំលែកថត ឬផ្ទុកឡើងឯកសារទៅម៉ាស៊ីនមេដែលអ្នកកំណត់។ វាមិនបង្កើតគណនីអ្នកអភិវឌ្ឍន៍ទេ។ អ្នកអភិវឌ្ឍន៍មិនដំណើរការម៉ាស៊ីនមេដែលទទួលឯកសារ ពាក្យសម្ងាត់ ឬទិន្នន័យប្រើប្រាស់របស់អ្នកទេ។

## ទិន្នន័យដែលអ្នកអភិវឌ្ឍន៍មិនប្រមូល

កម្មវិធីមិនមានការផ្សាយពាណិជ្ជកម្ម ការវិភាគ របាយការណ៍គាំង ឬ SDK តាមដានទេ។ អ្នកអភិវឌ្ឍន៍មិនប្រមូល លក់ ឬចែករំលែកទិន្នន័យផ្ទាល់ខ្លួនទេ។

## ទិន្នន័យដែលរក្សាទុកនៅលើកុំព្យូទ័ររបស់អ្នក

### កិច្ចការ និងការកំណត់

និយមន័យកិច្ចការត្រូវបានរក្សាទុកតែនៅលើកុំព្យូទ័រនេះ។ កិច្ចការអាចមានផ្លូវថត កាលវិភាគ ការកំណត់ការផ្ទុក និងពាក្យសម្ងាត់ ឬថូខឹនដែលអ្នកវាយ។ ពាក្យសម្ងាត់ និងអាថ៌កំបាំងផ្ទុកត្រូវបានអ៊ិនគ្រីបនៅលើកុំព្យូទ័រនេះមុនពេលរក្សាទុក ហើយអាចអានបានតែនៅលើកុំព្យូទ័រនេះ។ តម្លៃទាំងនេះមិនត្រូវបានផ្ទុកឡើងទៅអ្នកអភិវឌ្ឍន៍ទេ។

- កិច្ចការ Windows៖ `%AppData%\BUtil Backup Tasks`
- កិច្ចការ Linux៖ `~/.config/BUtil Backup Tasks`
- ការកំណត់ Windows (រួមទាំងស្បែក និងភាសាដែលបានជ្រើសចុងក្រោយសម្រាប់អាជ្ញាបណ្ណ ឬឯកជនភាព)៖ `%AppData%\BUtil\Settings\v1`
- ការកំណត់ Linux៖ `~/.config/BUtil/Settings/v1`
- ស្ថានភាពកិច្ចការ Windows៖ `%AppData%\BUtil\States`
- ស្ថានភាពកិច្ចការ Linux៖ `~/.config/BUtil/States`
- ស្ថានភាពនាំចូលមេឌៀ Windows៖ `%AppData%\BUtil Backup Tasks - States`
- ស្ថានភាពនាំចូលមេឌៀ Linux៖ `~/.config/BUtil Backup Tasks - States`

### ឯកសារដែលអ្នកជ្រើស

ការបម្រុងទុក សមកាលកម្ម ការស្ដារ និងការនាំចូលអាន និងសរសេរថតដែលអ្នកជ្រើស។ ឯកសារទាំងនោះនៅលើកុំព្យូទ័រនេះ ឬនៅគោលដៅផ្ទុកដែលអ្នកកំណត់។ កម្មវិធីមិនផ្ទុកឡើងទៅអ្នកអភិវឌ្ឍន៍ទេ។

### កំណត់ហេតុ

កំណត់ហេតុវិនិច្ឆ័យត្រូវបានសរសេរតែនៅលើកុំព្យូទ័រនេះ៖

- Windows៖ `%LocalAppData%\BUtil\logs\v4`
- Linux៖ `~/.local/share/BUtil/logs/v4`

ឯកសារទាំងនោះមិនត្រូវបានផ្ញើទៅកន្លែងណាទេ។

មិនមានម៉ាស៊ីនមេរបស់អ្នកអភិវឌ្ឍន៍ត្រូវបានប្រើដើម្បីរក្សាទុកទិន្នន័យរបស់អ្នកទេ។

## ការប្រើបណ្ដាញ

### គោលដៅដែលអ្នកកំណត់

ពេលកិច្ចការដំណើរការ កម្មវិធីភ្ជាប់តែទៅកន្លែងដែលអ្នកកំណត់។ វាអាចជាថតក្នុងមូលដ្ឋាន ឬម៉ាស៊ីនមេដែលអ្នកបញ្ចូល៖ FTP, FTPS, SFTP, WebDAV, SMB, NFS, ការផ្ទុកដែលត្រូវគ្នាជាមួយ S3 ឬ Azure Blob Storage។ ឈ្មោះឯកសារ ខ្លឹមសារ និងព័ត៌មានសម្គាល់ដែលអ្នកបញ្ចូលត្រូវបានផ្ញើទៅម៉ាស៊ីនមេនោះ ដើម្បីឱ្យកិច្ចការអាចដំណើរការ។ សេវានីមួយៗមានគោលការណ៍ឯកជនភាពផ្ទាល់ខ្លួន។ អ្នកអភិវឌ្ឍន៍មិនទទួលចរាចរណ៍នោះទេ។

BUtil Server អាចស្ដាប់នៅលើកុំព្យូទ័រនេះ ដើម្បីឱ្យម៉ាស៊ីនភ្ញៀវ BUtil ដែលអ្នកកំណត់អាចផ្ញើឯកសារ។ ចរាចរណ៍នោះនៅចន្លោះកុំព្យូទ័រដែលអ្នករៀបចំ។

## កាលវិភាគ

នៅលើ Windows អ្នកអាចដំណើរការកិច្ចការពេលចូល ឬតាមកាលវិភាគប្រចាំសប្តាហ៍។ កម្មវិធីចុះឈ្មោះវានៅក្នុង Windows Task Scheduler ដោយឈ្មោះដែលចាប់ផ្ដើមដោយ `BUtil`។ នេះគ្រាន់តែចាប់ផ្ដើមកម្មវិធីនេះនៅលើកុំព្យូទ័ររបស់អ្នក។
