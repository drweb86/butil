# Πολιτική απορρήτου

Τελευταία ενημέρωση: 25 Σεπτεμβρίου 2026

**BUtil** by Siarhei Kuchuk

Όνομα εφαρμογής: BUtil
Όνομα προγραμματιστή: Siarhei Kuchuk

Το BUtil δημιουργεί αντίγραφα ασφαλείας, συγχρονίζει και επαναφέρει αρχεία σε αυτόν τον υπολογιστή. Μπορεί επίσης να εισάγει πολυμέσα, να κοινοποιεί έναν φάκελο ή να ανεβάζει αρχεία σε διακομιστή που ρυθμίζετε. Δεν δημιουργεί λογαριασμό προγραμματιστή. Ο προγραμματιστής δεν λειτουργεί διακομιστή που λαμβάνει τα αρχεία, τους κωδικούς ή τα δεδομένα χρήσης σας.

## Δεδομένα που δεν συλλέγει ο προγραμματιστής

Η εφαρμογή δεν περιλαμβάνει διαφημίσεις, αναλυτικά, αναφορές σφαλμάτων ή SDK παρακολούθησης. Ο προγραμματιστής δεν συλλέγει, δεν πωλεί και δεν κοινοποιεί προσωπικά δεδομένα.

## Δεδομένα που αποθηκεύονται στον υπολογιστή σας

### Εργασίες και ρυθμίσεις

Οι ορισμοί εργασιών αποθηκεύονται μόνο σε αυτόν τον υπολογιστή. Μια εργασία μπορεί να περιλαμβάνει διαδρομές φακέλων, χρονοδιάγραμμα, ρυθμίσεις αποθήκευσης και κωδικούς ή διακριτικά που πληκτρολογείτε. Οι κωδικοί και τα μυστικά αποθήκευσης κρυπτογραφούνται σε αυτόν τον υπολογιστή πριν αποθηκευτούν και μπορούν να διαβαστούν μόνο σε αυτόν τον υπολογιστή. Οι τιμές αυτές δεν αποστέλλονται στον προγραμματιστή.

- Εργασίες Windows: `%AppData%\BUtil Backup Tasks`
- Εργασίες Linux: `~/.config/BUtil Backup Tasks`
- Ρυθμίσεις Windows (συμπεριλαμβανομένου του θέματος και της γλώσσας που επιλέχθηκε τελευταία για την άδεια ή το απόρρητο): `%AppData%\BUtil\Settings\v1`
- Ρυθμίσεις Linux: `~/.config/BUtil/Settings/v1`
- Κατάσταση εργασιών Windows: `%AppData%\BUtil\States`
- Κατάσταση εργασιών Linux: `~/.config/BUtil/States`
- Κατάσταση εισαγωγής πολυμέσων Windows: `%AppData%\BUtil Backup Tasks - States`
- Κατάσταση εισαγωγής πολυμέσων Linux: `~/.config/BUtil Backup Tasks - States`

### Αρχεία που επιλέγετε

Η δημιουργία αντιγράφων, ο συγχρονισμός, η επαναφορά και η εισαγωγή διαβάζουν και γράφουν τους φακέλους που επιλέγετε. Τα αρχεία αυτά παραμένουν σε αυτόν τον υπολογιστή ή στον προορισμό αποθήκευσης που ρυθμίζετε. Η εφαρμογή δεν τα ανεβάζει στον προγραμματιστή.

### Αρχεία καταγραφής

Τα διαγνωστικά αρχεία καταγραφής γράφονται μόνο σε αυτόν τον υπολογιστή:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

Τα αρχεία αυτά δεν αποστέλλονται πουθενά.

Δεν χρησιμοποιείται διακομιστής του προγραμματιστή για την αποθήκευση των δεδομένων σας.

## Χρήση δικτύου

### Προορισμοί που ρυθμίζετε

Όταν εκτελείται μια εργασία, η εφαρμογή συνδέεται μόνο στο σημείο που ορίζετε. Μπορεί να είναι τοπικός φάκελος ή διακομιστής που εισάγετε: FTP, FTPS, SFTP, WebDAV, SMB, NFS, αποθήκευση συμβατή με S3 ή Azure Blob Storage. Τα ονόματα αρχείων, το περιεχόμενο και τα διαπιστευτήρια που εισαγάγατε αποστέλλονται σε αυτόν τον διακομιστή ώστε να εκτελεστεί η εργασία. Κάθε τέτοια υπηρεσία έχει τη δική της πολιτική απορρήτου. Ο προγραμματιστής δεν λαμβάνει αυτή την κίνηση.

Ο BUtil Server μπορεί να ακούει σε αυτόν τον υπολογιστή ώστε ένας πελάτης BUtil που ρυθμίζετε να μπορεί να στέλνει αρχεία. Η κίνηση αυτή παραμένει μεταξύ των υπολογιστών που ρυθμίζετε.

### Έλεγχος ενημερώσεων

Οι εκδόσεις εκτός Store μπορεί να ζητήσουν την πιο πρόσφατη έκδοση στο GitHub:

`https://api.github.com/repos/drweb86/butil/releases/latest`

Το GitHub (Microsoft) λαμβάνει ένα συνηθισμένο αίτημα HTTPS (διεύθυνση IP, user-agent, ώρα). Ο προγραμματιστής δεν λαμβάνει αυτή την κίνηση.

Οι εγκαταστάσεις από το Microsoft Store δεν χρησιμοποιούν αυτόν τον έλεγχο· το Store παραδίδει τις ενημερώσεις.

### Σύνδεσμοι που ανοίγετε

Η εφαρμογή μπορεί να ανοίξει αυτές τις σελίδες στο πρόγραμμα περιήγησης του συστήματος. Οι ιστότοποι αυτοί έχουν τις δικές τους πολιτικές απορρήτου:

- Αρχική σελίδα έργου: [github.com/drweb86/butil](https://github.com/drweb86/butil)
- Πιο πρόσφατη έκδοση: [github.com/drweb86/butil/releases/latest](https://github.com/drweb86/butil/releases/latest)
- Βοήθεια μοτίβων αρχείων: [learn.microsoft.com file globbing](https://learn.microsoft.com/en-us/dotnet/core/extensions/file-globbing#pattern-formats)
- Βοήθεια μορφής ημερομηνίας: [learn.microsoft.com custom date and time format strings](https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings)
- Πηγές εικονιδίων: [github.com/drweb86/butil Icons](https://github.com/drweb86/butil/blob/master/help/Icons.md)

Η άδεια και αυτή η πολιτική απορρήτου εμφανίζονται μέσα στην εφαρμογή. Δεν ανοίγουν ως ιστοσελίδες.

## Χρονοδιάγραμμα

Στα Windows μπορείτε να εκτελείτε μια εργασία κατά τη σύνδεση ή με εβδομαδιαίο χρονοδιάγραμμα. Η εφαρμογή την καταχωρίζει στον Χρονοπρογραμματιστή εργασιών των Windows με όνομα που αρχίζει από `BUtil`. Αυτό απλώς εκκινεί την εφαρμογή στον υπολογιστή σας.
