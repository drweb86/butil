# గోప్యతా విధానం

చివరి నవీకరణ: 25 సెప్టెంబర్ 2026

**BUtil** by Siarhei Kuchuk

అప్లికేషన్ పేరు: BUtil
డెవలపర్ పేరు: Siarhei Kuchuk

BUtil ఈ కంప్యూటర్‌లో ఫైళ్లను బ్యాకప్ చేస్తుంది, సింక్ చేస్తుంది, పునరుద్ధరిస్తుంది. ఇది మీడియాను దిగుమతి చేయగలదు, ఫోల్డర్‌ను పంచుకోగలదు లేదా మీరు సెట్ చేసిన సర్వర్‌కు ఫైళ్లను అప్‌లోడ్ చేయగలదు. ఇది డెవలపర్ ఖాతాను సృష్టించదు. డెవలపర్ మీ ఫైళ్లు, పాస్‌వర్డ్‌లు లేదా వినియోగ డేటాను స్వీకరించే సర్వర్‌ను నడపరు.

## డెవలపర్ సేకరించని డేటా

యాప్‌లో ప్రకటనలు, విశ్లేషణ, క్రాష్ నివేదికలు లేదా ట్రాకింగ్ SDK లేవు. డెవలపర్ వ్యక్తిగత డేటాను సేకరించరు, అమ్మరు లేదా పంచుకోరు.

## మీ కంప్యూటర్‌లో నిల్వ అయ్యే డేటా

### పనులు మరియు సెట్టింగ్‌లు

పని నిర్వచనాలు ఈ కంప్యూటర్‌లో మాత్రమే నిల్వ అవుతాయి. పనిలో ఫోల్డర్ మార్గాలు, షెడ్యూల్, నిల్వ సెట్టింగ్‌లు, మీరు టైప్ చేసిన పాస్‌వర్డ్‌లు లేదా టోకెన్‌లు ఉండవచ్చు. పాస్‌వర్డ్‌లు మరియు నిల్వ రహస్యాలు సేవ్ చేయడానికి ముందు ఈ కంప్యూటర్‌లో ఎన్‌క్రిప్ట్ అవుతాయి, ఈ కంప్యూటర్‌లో మాత్రమే చదవగలవు. ఆ విలువలు డెవలపర్‌కు పంపబడవు.

- Windows పనులు: `%AppData%\BUtil Backup Tasks`
- Linux పనులు: `~/.config/BUtil Backup Tasks`
- Windows సెట్టింగ్‌లు (థీమ్ మరియు లైసెన్స్ లేదా గోప్యత కోసం చివరగా ఎంచుకున్న భాషతో సహా): `%AppData%\BUtil\Settings\v1`
- Linux సెట్టింగ్‌లు: `~/.config/BUtil/Settings/v1`
- Windows పని స్థితి: `%AppData%\BUtil\States`
- Linux పని స్థితి: `~/.config/BUtil/States`
- Windows మీడియా దిగుమతి స్థితి: `%AppData%\BUtil Backup Tasks - States`
- Linux మీడియా దిగుమతి స్థితి: `~/.config/BUtil Backup Tasks - States`

### మీరు ఎంచుకున్న ఫైళ్లు

బ్యాకప్, సింక్, పునరుద్ధరణ, దిగుమతి మీరు ఎంచుకున్న ఫోల్డర్‌లను చదివి రాస్తాయి. ఆ ఫైళ్లు ఈ కంప్యూటర్‌లో లేదా మీరు సెట్ చేసిన నిల్వలో ఉంటాయి. యాప్ వాటిని డెవలపర్‌కు పంపదు.

### లాగ్‌లు

నిర్ధారణ లాగ్‌లు ఈ కంప్యూటర్‌లో మాత్రమే రాయబడతాయి:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

ఆ ఫైళ్లు ఎక్కడికీ పంపబడవు.

మీ డేటాను నిల్వ చేయడానికి డెవలపర్ సర్వర్ ఉపయోగించబడదు.

## నెట్‌వర్క్ వినియోగం

### మీరు సెట్ చేసే గమ్యాలు

పని నడిచేటప్పుడు యాప్ మీరు నిర్ణయించిన చోటుకు మాత్రమే కనెక్ట్ అవుతుంది. అది స్థానిక ఫోల్డర్ లేదా మీరు నమోదు చేసిన సర్వర్ కావచ్చు: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-అనుకూల నిల్వ లేదా Azure Blob Storage. ఫైల్ పేర్లు, కంటెంట్, మీరు నమోదు చేసిన ఆధారాలు పని నడవడానికి ఆ సర్వర్‌కు పంపబడతాయి. ప్రతి సేవకు సొంత గోప్యతా విధానం ఉంటుంది. డెవలపర్ ఆ ట్రాఫిక్‌ను పొందరు.

BUtil Server ఈ కంప్యూటర్‌లో వినవచ్చు, తద్వారా మీరు సెట్ చేసిన BUtil క్లయింట్ ఫైళ్లను పంపగలదు. ఆ ట్రాఫిక్ మీరు సెట్ చేసిన కంప్యూటర్‌ల మధ్య ఉంటుంది.

Microsoft Store నుండి ఇన్‌స్టాల్‌లు ఈ తనిఖీని ఉపయోగించవు; నవీకరణలను Store అందిస్తుంది.

## షెడ్యూల్

Windows లో సైన్-ఇన్ సమయంలో లేదా వారపు షెడ్యూల్‌లో పనిని నడపవచ్చు. యాప్ దీన్ని Windows Task Scheduler లో `BUtil` తో మొదలయ్యే పేరుతో నమోదు చేస్తుంది. ఇది ఈ యాప్‌ను మీ కంప్యూటర్‌లో మాత్రమే ప్రారంభిస్తుంది.

## పిల్లలు

యాప్ బ్యాకప్ మరియు ఫైల్ సింక్ సాధనం. ఇది 13 సంవత్సరాల కంటే తక్కువ పిల్లల కోసం కాదు.

GitHub నవీకరణ తనిఖీ అభ్యర్థనను మరియు మీరు తెరిచే పేజీలను పైన వివరించినట్లు ప్రాసెస్ చేస్తుంది. Microsoft Store, Store ఇన్‌స్టాల్‌లు మరియు నవీకరణలను ప్రాసెస్ చేస్తుంది. మీరు సెట్ చేసే నిల్వ ప్రదాతలు పని పంపే ఫైళ్లు మరియు ఆధారాలను ప్రాసెస్ చేస్తారు. డెవలపర్ ఆ ట్రాఫిక్‌ను పొందరు.
