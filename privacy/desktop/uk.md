# Політика конфіденційності

Останнє оновлення: 25 вересня 2026 р.

**BUtil** by Siarhei Kuchuk

Назва застосунку: BUtil
Ім’я розробника: Siarhei Kuchuk

BUtil створює резервні копії, синхронізує та відновлює файли на цьому комп’ютері. Програма також може імпортувати медіафайли, надавати спільний доступ до папки або надсилати файли на сервер, який ви вказуєте. Вона не створює обліковий запис розробника. Розробник не використовує сервер, який отримує ваші файли, паролі або дані про використання.

## Дані, які розробник не збирає

У застосунку немає реклами, аналітики, надсилання звітів про збої та SDK відстеження. Розробник не збирає, не продає і не передає персональні дані.

## Дані, що зберігаються на вашому комп’ютері

### Завдання та параметри

Описи завдань зберігаються лише на цьому комп’ютері. Завдання може містити шляхи до папок, розклад, параметри сховища, а також паролі або токени, які ви вводите. Паролі та секрети сховища шифруються на цьому комп’ютері перед збереженням, і прочитати їх можна лише на цьому комп’ютері. Ці значення не надсилаються розробнику.

- Завдання Windows: `%AppData%\BUtil Backup Tasks`
- Завдання Linux: `~/.config/BUtil Backup Tasks`
- Параметри Windows (включно з темою та мовою, останньою вибраною для ліцензії або політики конфіденційності): `%AppData%\BUtil\Settings\v1`
- Параметри Linux: `~/.config/BUtil/Settings/v1`
- Стан завдань Windows: `%AppData%\BUtil\States`
- Стан завдань Linux: `~/.config/BUtil/States`
- Стан імпорту медіа Windows: `%AppData%\BUtil Backup Tasks - States`
- Стан імпорту медіа Linux: `~/.config/BUtil Backup Tasks - States`

### Файли, які ви обираєте

Резервне копіювання, синхронізація, відновлення та імпорт читають і записують вибрані вами папки. Ці файли залишаються на цьому комп’ютері або в сховищі, яке ви налаштовуєте. Застосунок не надсилає їх розробнику.

### Журнали

Діагностичні журнали записуються лише на цьому комп’ютері:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

Ці файли нікуди не надсилаються.

Сервер розробника не використовується для зберігання ваших даних.

## Використання мережі

### Місця, які ви налаштовуєте

Коли завдання виконується, застосунок підключається лише до вказаного вами місця. Це може бути локальна папка або сервер, який ви вводите: FTP, FTPS, SFTP, WebDAV, SMB, NFS, сховище, сумісне з S3, або Azure Blob Storage. Імена файлів, вміст файлів і введені вами облікові дані надсилаються на цей сервер, щоб завдання могло виконатися. Кожна така служба має власну політику конфіденційності. Розробник цей трафік не отримує.

BUtil Server може очікувати підключення на цьому комп’ютері, щоб налаштований вами клієнт BUtil міг надсилати файли. Цей трафік залишається між комп’ютерами, які ви налаштували.

### Перевірка оновлень

Збірки не з Store можуть запитувати останній випуск на GitHub:

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) отримує звичайний запит HTTPS (IP-адреса, user-agent, час). Розробник цей трафік не отримує.

Встановлення з Microsoft Store цю перевірку не використовують; оновлення доставляє Store.

### Посилання, які ви відкриваєте

Застосунок може відкривати ці сторінки в системному браузері. Ці сайти мають власні політики конфіденційності:

- Сторінка проєкту: [github.com/drweb86/butil](https://github.com/drweb86/butil)
- Останній випуск: [github.com/drweb86/butil/releases/latest](https://github.com/drweb86/butil/releases/latest)
- Довідка щодо шаблонів файлів: [learn.microsoft.com file globbing](https://learn.microsoft.com/en-us/dotnet/core/extensions/file-globbing#pattern-formats)
- Довідка щодо формату дати: [learn.microsoft.com custom date and time format strings](https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings)
- Автори піктограм: [github.com/drweb86/butil Icons](https://github.com/drweb86/butil/blob/master/help/Icons.md)

Ліцензія і ця політика конфіденційності показуються всередині застосунку. Вони не відкриваються як вебсторінки.

## Розклад

У Windows завдання можна запускати під час входу або за тижневим розкладом. Застосунок реєструє це в Планувальнику завдань Windows під іменем, яке починається з `BUtil`. Це лише запускає цей застосунок на вашому комп’ютері.

## Діти

Застосунок призначений для резервного копіювання та синхронізації файлів. Він не орієнтований на дітей віком до 13 років.

## Треті сторони

GitHub обробляє запит перевірки оновлень і сторінки, які ви відкриваєте, як описано вище. Microsoft Store обробляє встановлення та оновлення з Store. Постачальники сховищ, яких ви налаштовуєте, обробляють файли та облікові дані, які завдання їм надсилає. Розробник цей трафік не отримує.
