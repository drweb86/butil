# தனியுரிமைக் கொள்கை

கடைசி புதுப்பிப்பு: 25 செப்டம்பர் 2026

**BUtil** by Siarhei Kuchuk

பயன்பாட்டின் பெயர்: BUtil
உருவாக்குநரின் பெயர்: Siarhei Kuchuk

BUtil இந்தக் கணினியில் கோப்புகளை காப்புப் பிரதி எடுக்கிறது, ஒத்திசைக்கிறது, மீட்டமைக்கிறது. இது ஊடகத்தை இறக்குமதி செய்யலாம், கோப்புறையைப் பகிரலாம், அல்லது நீங்கள் அமைத்த சேவையகத்திற்குக் கோப்புகளைப் பதிவேற்றலாம். இது உருவாக்குநர் கணக்கை உருவாக்காது. உருவாக்குநர் உங்கள் கோப்புகள், கடவுச்சொற்கள் அல்லது பயன்பாட்டுத் தரவைப் பெறும் சேவையகத்தை இயக்கவில்லை.

## உருவாக்குநர் சேகரிக்காத தரவு

பயன்பாட்டில் விளம்பரங்கள், பகுப்பாய்வு, செயலிழப்பு அறிக்கைகள் அல்லது கண்காணிப்பு SDK இல்லை. உருவாக்குநர் தனிப்பட்ட தரவைச் சேகரிக்கவில்லை, விற்கவில்லை அல்லது பகிரவில்லை.

## உங்கள் கணினியில் சேமிக்கப்படும் தரவு

### பணிகளும் அமைப்புகளும்

பணி வரையறைகள் இந்தக் கணினியில் மட்டும் சேமிக்கப்படுகின்றன. ஒரு பணியில் கோப்புறை பாதைகள், அட்டவணை, சேமிப்பக அமைப்புகள், நீங்கள் தட்டச்சு செய்யும் கடவுச்சொற்கள் அல்லது டோக்கன்கள் இருக்கலாம். கடவுச்சொற்களும் சேமிப்பக இரகசியங்களும் சேமிக்கப்படுவதற்கு முன் இந்தக் கணினியில் மறைகுறியாக்கப்படுகின்றன, இந்தக் கணினியில் மட்டுமே படிக்க முடியும். அந்த மதிப்புகள் உருவாக்குநருக்கு அனுப்பப்படுவதில்லை.

- Windows பணிகள்: `%AppData%\BUtil Backup Tasks`
- Linux பணிகள்: `~/.config/BUtil Backup Tasks`
- Windows அமைப்புகள் (தீம் மற்றும் உரிமம் அல்லது தனியுரிமைக்கு கடைசியாகத் தேர்ந்தெடுத்த மொழி உட்பட): `%AppData%\BUtil\Settings\v1`
- Linux அமைப்புகள்: `~/.config/BUtil/Settings/v1`
- Windows பணி நிலை: `%AppData%\BUtil\States`
- Linux பணி நிலை: `~/.config/BUtil/States`
- Windows ஊடக இறக்குமதி நிலை: `%AppData%\BUtil Backup Tasks - States`
- Linux ஊடக இறக்குமதி நிலை: `~/.config/BUtil Backup Tasks - States`

### நீங்கள் தேர்ந்தெடுக்கும் கோப்புகள்

காப்புப் பிரதி, ஒத்திசைவு, மீட்டமைப்பு, இறக்குமதி ஆகியவை நீங்கள் தேர்ந்தெடுக்கும் கோப்புறைகளைப் படித்து எழுதுகின்றன. அந்தக் கோப்புகள் இந்தக் கணினியில் அல்லது நீங்கள் அமைத்த சேமிப்பகத்தில் இருக்கும். பயன்பாடு அவற்றை உருவாக்குநருக்குப் பதிவேற்றாது.

### பதிவுகள்

கண்டறியும் பதிவுகள் இந்தக் கணினியில் மட்டும் எழுதப்படுகின்றன:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

அந்தக் கோப்புகள் எங்கும் அனுப்பப்படுவதில்லை.

உங்கள் தரவைச் சேமிக்க உருவாக்குநர் சேவையகம் பயன்படுத்தப்படுவதில்லை.

## பிணையப் பயன்பாடு

### நீங்கள் அமைக்கும் இடங்கள்

ஒரு பணி இயங்கும்போது, பயன்பாடு நீங்கள் நிர்ணயித்த இடத்துடன் மட்டுமே இணைகிறது. அது உள்ளூர் கோப்புறை அல்லது நீங்கள் உள்ளிடும் சேவையகமாக இருக்கலாம்: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-இணக்கமான சேமிப்பகம் அல்லது Azure Blob Storage. கோப்புப் பெயர்கள், உள்ளடக்கம், நீங்கள் உள்ளிட்ட சான்றுகள் பணி இயங்க அந்தச் சேவையகத்திற்கு அனுப்பப்படும். ஒவ்வொரு சேவைக்கும் சொந்த தனியுரிமைக் கொள்கை உண்டு. உருவாக்குநர் அந்தப் போக்குவரத்தைப் பெறுவதில்லை.

BUtil Server இந்தக் கணினியில் கேட்கலாம், அதனால் நீங்கள் அமைத்த BUtil வாடிக்கையாளர் கோப்புகளை அனுப்ப முடியும். அந்தப் போக்குவரத்து நீங்கள் அமைத்த கணினிகளுக்கு இடையே இருக்கும்.

### புதுப்பிப்புச் சோதனை

Microsoft Store நிறுவல்கள் இந்தச் சோதனையைப் பயன்படுத்துவதில்லை; புதுப்பிப்புகளை Store வழங்குகிறது.

## அட்டவணை

Windows இல் உள்நுழையும்போது அல்லது வாராந்திர அட்டவணையில் பணியை இயக்கலாம். பயன்பாடு இதை Windows Task Scheduler இல் `BUtil` என்று தொடங்கும் பெயரில் பதிவு செய்கிறது. இது இந்தப் பயன்பாட்டை உங்கள் கணினியில் மட்டும் தொடங்கும்.

## குழந்தைகள்

பயன்பாடு காப்புப் பிரதி மற்றும் கோப்பு ஒத்திசைவுக் கருவி. இது 13 வயதுக்குக் குறைந்த குழந்தைகளுக்கானது அல்ல.
