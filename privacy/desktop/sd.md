# رازداري پاليسي

آخري تازه ڪاري: 25 سيپٽمبر 2026

**BUtil** by Siarhei Kuchuk

ايپ جو نالو: BUtil
ڊولپر جو نالو: Siarhei Kuchuk

BUtil هن ڪمپيوٽر تي فائلن جو بيڪ اپ وٺي ٿو، انهن کي هم وقت ڪري ٿو ۽ بحال ڪري ٿو. اهو ميڊيا درآمد ڪري سگهي ٿو، فولڊر شيئر ڪري سگهي ٿو، يا فائلون ان سرور تي موڪلي سگهي ٿو جيڪو توهان سيٽ ڪيو. اهو ڊولپر اڪائونٽ نه ٺاهي. ڊولپر اهڙو سرور نه هلائي جيڪو توهان جون فائلون، پاسورڊ يا استعمال جو ڊيٽا وٺي.

## ڊيٽا جيڪو ڊولپر گڏ نه ڪري

ايپ ۾ اشتهار، تجزيو، ڪريش رپورٽ يا ٽريڪنگ SDK ناهي. ڊولپر ذاتي ڊيٽا گڏ، وڪرو يا شيئر نه ڪري.

## توهان جي ڪمپيوٽر تي محفوظ ڊيٽا

### ڪم ۽ سيٽنگون

ڪمن جون وصفون صرف هن ڪمپيوٽر تي محفوظ آهن. ڪم ۾ فولڊر جا رستا، شيڊول، اسٽوريج سيٽنگون ۽ توهان جا لکيل پاسورڊ يا ٽوڪن شامل ٿي سگهن ٿا. پاسورڊ ۽ اسٽوريج راز محفوظ ٿيڻ کان اڳ هن ڪمپيوٽر تي انڪرپٽ ٿين ٿا ۽ صرف هن ڪمپيوٽر تي پڙهي سگهجن ٿا. اهي قدر ڊولپر ڏانهن نه موڪليا وڃن.

- Windows ڪم: `%AppData%\BUtil Backup Tasks`
- Linux ڪم: `~/.config/BUtil Backup Tasks`
- Windows سيٽنگون (ٿيم ۽ لائسنس يا رازداري لاءِ آخري چونڊيل ٻولي سميت): `%AppData%\BUtil\Settings\v1`
- Linux سيٽنگون: `~/.config/BUtil/Settings/v1`
- Windows ڪم جي حالت: `%AppData%\BUtil\States`
- Linux ڪم جي حالت: `~/.config/BUtil/States`
- Windows ميڊيا درآمد جي حالت: `%AppData%\BUtil Backup Tasks - States`
- Linux ميڊيا درآمد جي حالت: `~/.config/BUtil Backup Tasks - States`

### فائلون جيڪي توهان چونڊيو

بيڪ اپ، هم وقت سازي، بحالي ۽ درآمد توهان جا چونڊيل فولڊر پڙهن ۽ لکن ٿا. اهي فائلون هن ڪمپيوٽر تي يا توهان جي سيٽ ڪيل اسٽوريج تي رهن ٿيون. ايپ انهن کي ڊولپر ڏانهن نه موڪلي.

### لاگ

تشخيصي لاگ صرف هن ڪمپيوٽر تي لکجن ٿا:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

اهي فائلون ڪٿي به نه موڪليون وڃن.

توهان جو ڊيٽا محفوظ ڪرڻ لاءِ ڊولپر جو سرور استعمال نه ٿئي.

## نيٽ ورڪ جو استعمال

### جايون جيڪي توهان سيٽ ڪيو

جڏهن ڪم هلي، ايپ صرف توهان جي مقرر ڪيل جڳهه سان ڳنڍجي. اهو مقامي فولڊر يا توهان جو داخل ڪيل سرور ٿي سگهي ٿو: FTP، FTPS، SFTP، WebDAV، SMB، NFS، S3 سان مطابقت رکندڙ اسٽوريج يا Azure Blob Storage. فائل جا نالا، مواد ۽ توهان جا داخل ڪيل سند ان سرور ڏانهن موڪليا وڃن ته جيئن ڪم هلي سگهي. هر خدمت جي پنهنجي رازداري پاليسي آهي. ڊولپر هي ٽريفڪ نه وٺي.

BUtil Server هن ڪمپيوٽر تي ٻڌي سگهي ٿو ته جيئن توهان جو سيٽ ڪيل BUtil ڪلائنٽ فائلون موڪلي سگهي. اهو ٽريفڪ توهان جي سيٽ ڪيل ڪمپيوٽرن جي وچ ۾ رهي.

## شيڊول

Windows تي توهان ڪم سائن ان تي يا هفتيوار شيڊول تي هلائي سگهو ٿا. ايپ ان کي Windows Task Scheduler ۾ اهڙي نالي سان رجسٽر ڪري جيڪو `BUtil` سان شروع ٿئي. هي صرف هي ايپ توهان جي ڪمپيوٽر تي شروع ڪري.
