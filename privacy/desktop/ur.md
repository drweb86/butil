# رازداری کی پالیسی

آخری تازہ کاری: 25 ستمبر 2026

**BUtil** by Siarhei Kuchuk

ایپ کا نام: BUtil
ڈیولپر کا نام: Siarhei Kuchuk

BUtil اس کمپیوٹر پر فائلوں کا بیک اپ لیتا ہے، انہیں ہم آہنگ کرتا ہے اور بحال کرتا ہے۔ یہ میڈیا درآمد کر سکتا ہے، فولڈر شیئر کر سکتا ہے، یا فائلیں اس سرور پر بھیج سکتا ہے جسے آپ ترتیب دیتے ہیں۔ یہ ڈیولپر اکاؤنٹ نہیں بناتا۔ ڈیولپر ایسا سرور نہیں چلاتا جو آپ کی فائلیں، پاس ورڈ یا استعمال کا ڈیٹا وصول کرے۔

## وہ ڈیٹا جو ڈیولپر جمع نہیں کرتا

ایپ میں اشتہارات، تجزیات، کریش رپورٹس یا ٹریکنگ SDK نہیں ہیں۔ ڈیولپر ذاتی ڈیٹا جمع، فروخت یا شیئر نہیں کرتا۔

## آپ کے کمپیوٹر پر محفوظ ڈیٹا

### کام اور ترتیبات

کام کی تعریفیں صرف اس کمپیوٹر پر محفوظ ہوتی ہیں۔ ایک کام میں فولڈر کے راستے، شیڈول، اسٹوریج کی ترتیبات اور وہ پاس ورڈ یا ٹوکن شامل ہو سکتے ہیں جو آپ لکھتے ہیں۔ پاس ورڈ اور اسٹوریج کے راز محفوظ ہونے سے پہلے اس کمپیوٹر پر خفیہ کیے جاتے ہیں اور صرف اسی کمپیوٹر پر پڑھے جا سکتے ہیں۔ یہ قدریں ڈیولپر کو نہیں بھیجی جاتیں۔

- Windows کام: `%AppData%\BUtil Backup Tasks`
- Linux کام: `~/.config/BUtil Backup Tasks`
- Windows ترتیبات (تھیم اور لائسنس یا رازداری کے لیے آخری منتخب زبان سمیت): `%AppData%\BUtil\Settings\v1`
- Linux ترتیبات: `~/.config/BUtil/Settings/v1`
- Windows کام کی حالت: `%AppData%\BUtil\States`
- Linux کام کی حالت: `~/.config/BUtil/States`
- Windows میڈیا درآمد کی حالت: `%AppData%\BUtil Backup Tasks - States`
- Linux میڈیا درآمد کی حالت: `~/.config/BUtil Backup Tasks - States`

### وہ فائلیں جو آپ منتخب کرتے ہیں

بیک اپ، ہم آہنگی، بحالی اور درآمد آپ کے منتخب فولڈرز پڑھتے اور لکھتے ہیں۔ وہ فائلیں اس کمپیوٹر یا آپ کے ترتیب دیے اسٹوریج پر رہتی ہیں۔ ایپ انہیں ڈیولپر کو نہیں بھیجتی۔

### لاگز

تشخیصی لاگز صرف اس کمپیوٹر پر لکھے جاتے ہیں:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

یہ فائلیں کہیں نہیں بھیجی جاتیں۔

آپ کا ڈیٹا محفوظ کرنے کے لیے ڈیولپر کا کوئی سرور استعمال نہیں ہوتا۔

## نیٹ ورک کا استعمال

### وہ مقامات جو آپ ترتیب دیتے ہیں

جب کوئی کام چلتا ہے تو ایپ صرف اس جگہ سے جڑتی ہے جو آپ مقرر کرتے ہیں۔ یہ مقامی فولڈر یا آپ کا درج کردہ سرور ہو سکتا ہے: FTP، FTPS، SFTP، WebDAV، SMB، NFS، S3 سے ہم آہنگ اسٹوریج یا Azure Blob Storage۔ فائل کے نام، مواد اور آپ کے درج کردہ اسناد اس سرور کو بھیجے جاتے ہیں تاکہ کام چل سکے۔ ان میں سے ہر سروس کی اپنی رازداری پالیسی ہے۔ ڈیولپر یہ ٹریفک وصول نہیں کرتا۔

BUtil Server اس کمپیوٹر پر سن سکتا ہے تاکہ آپ کا ترتیب دیا BUtil کلائنٹ فائلیں بھیج سکے۔ یہ ٹریفک آپ کے ترتیب دیے کمپیوٹروں کے درمیان رہتا ہے۔
