# ગોપનીયતા નીતિ

છેલ્લું અપડેટ: 25 સપ્ટેમ્બર 2026

**BUtil** by Siarhei Kuchuk

એપનું નામ: BUtil
ડેવલપરનું નામ: Siarhei Kuchuk

BUtil આ કમ્પ્યુટર પર ફાઇલોનું બેકઅપ લે છે, તેમને સિંક કરે છે અને પુનઃસ્થાપિત કરે છે. તે મીડિયા આયાત કરી શકે, ફોલ્ડર શેર કરી શકે અથવા તમે ગોઠવેલા સર્વર પર ફાઇલો અપલોડ કરી શકે. તે ડેવલપર ખાતું બનાવતું નથી. ડેવલપર એવું સર્વર ચલાવતા નથી જે તમારી ફાઇલો, પાસવર્ડ અથવા ઉપયોગ ડેટા મેળવે.

## ડેટા જે ડેવલપર એકત્ર કરતા નથી

એપમાં જાહેરાતો, વિશ્લેષણ, ક્રેશ રિપોર્ટ અથવા ટ્રેકિંગ SDK નથી. ડેવલપર વ્યક્તિગત ડેટા એકત્ર, વેચતા કે શેર કરતા નથી.

## તમારા કમ્પ્યુટર પર સંગ્રહિત ડેટા

### કાર્યો અને સેટિંગ્સ

કાર્યની વ્યાખ્યાઓ ફક્ત આ કમ્પ્યુટર પર સંગ્રહિત થાય છે. કાર્યમાં ફોલ્ડર પાથ, શેડ્યૂલ, સ્ટોરેજ સેટિંગ્સ અને તમે લખેલા પાસવર્ડ અથવા ટોકન હોઈ શકે. પાસવર્ડ અને સ્ટોરેજ રહસ્યો સાચવતા પહેલાં આ કમ્પ્યુટર પર એન્ક્રિપ્ટ થાય છે અને ફક્ત આ કમ્પ્યુટર પર વાંચી શકાય છે. આ મૂલ્યો ડેવલપરને મોકલાતા નથી.

- Windows કાર્યો: `%AppData%\BUtil Backup Tasks`
- Linux કાર્યો: `~/.config/BUtil Backup Tasks`
- Windows સેટિંગ્સ (થીમ અને લાઇસન્સ અથવા ગોપનીયતા માટે છેલ્લે પસંદ કરેલી ભાષા સહિત): `%AppData%\BUtil\Settings\v1`
- Linux સેટિંગ્સ: `~/.config/BUtil/Settings/v1`
- Windows કાર્ય સ્થિતિ: `%AppData%\BUtil\States`
- Linux કાર્ય સ્થિતિ: `~/.config/BUtil/States`
- Windows મીડિયા આયાત સ્થિતિ: `%AppData%\BUtil Backup Tasks - States`
- Linux મીડિયા આયાત સ્થિતિ: `~/.config/BUtil Backup Tasks - States`

### તમે પસંદ કરેલી ફાઇલો

બેકઅપ, સિંક, પુનઃસ્થાપન અને આયાત તમે પસંદ કરેલા ફોલ્ડર વાંચે અને લખે છે. તે ફાઇલો આ કમ્પ્યુટર પર અથવા તમે ગોઠવેલા સ્ટોરેજ પર રહે છે. એપ તેમને ડેવલપરને મોકલતી નથી.

### લોગ

નિદાન લોગ ફક્ત આ કમ્પ્યુટર પર લખાય છે:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

તે ફાઇલો ક્યાંય મોકલાતી નથી.

તમારો ડેટા સંગ્રહવા માટે ડેવલપરનું સર્વર વપરાતું નથી.

## નેટવર્ક ઉપયોગ

### તમે ગોઠવેલા સ્થળો

જ્યારે કાર્ય ચાલે છે, એપ ફક્ત તમે નક્કી કરેલા સ્થળ સાથે જોડાય છે. તે સ્થાનિક ફોલ્ડર અથવા તમે દાખલ કરેલું સર્વર હોઈ શકે: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-સુસંગત સ્ટોરેજ અથવા Azure Blob Storage. ફાઇલ નામ, સામગ્રી અને તમે દાખલ કરેલી ઓળખપત્રો તે સર્વર પર મોકલાય છે જેથી કાર્ય ચાલી શકે. દરેક સેવાની પોતાની ગોપનીયતા નીતિ છે. ડેવલપરને આ ટ્રાફિક મળતો નથી.

BUtil Server આ કમ્પ્યુટર પર સાંભળી શકે છે જેથી તમે ગોઠવેલો BUtil ક્લાયન્ટ ફાઇલો મોકલી શકે. તે ટ્રાફિક તમે ગોઠવેલા કમ્પ્યુટર વચ્ચે રહે છે.

Microsoft Store માંથી ઇન્સ્ટોલ આ તપાસ વાપરતા નથી; અપડેટ Store આપે છે.

## શેડ્યૂલ

Windows પર તમે સાઇન-ઇન વખતે અથવા સાપ્તાહિક શેડ્યૂલ પર કાર્ય ચલાવી શકો છો. એપ તેને Windows Task Scheduler માં `BUtil` થી શરૂ થતા નામથી નોંધે છે. આ ફક્ત આ એપ તમારા કમ્પ્યુટર પર શરૂ કરે છે.
