# ଗୋପନୀୟତା ନୀତି

ଶେଷ ଅଦ୍ୟତନ: ୨୫ ସେପ୍ଟେମ୍ବର ୨୦୨୬

**BUtil** by Siarhei Kuchuk

ଆପ୍ଲିକେସନ୍ ନାମ: BUtil
ବିକାଶକାରୀଙ୍କ ନାମ: Siarhei Kuchuk

BUtil ଏହି କମ୍ପ୍ୟୁଟରରେ ଫାଇଲ୍ ବ୍ୟାକଅପ୍ କରେ, ସିଙ୍କ୍ କରେ ଏବଂ ପୁନରୁଦ୍ଧାର କରେ। ଏହା ମିଡ଼ିଆ ଆମଦାନି କରିପାରେ, ଫୋଲ୍ଡର୍ ଅଂଶୀଦାର କରିପାରେ କିମ୍ବା ଆପଣ ସେଟ୍ କରିଥିବା ସର୍ଭରକୁ ଫାଇଲ୍ ଅପଲୋଡ୍ କରିପାରେ। ଏହା ବିକାଶକାରୀ ଖାତା ସୃଷ୍ଟି କରେ ନାହିଁ। ବିକାଶକାରୀ ଏପରି ସର୍ଭର ଚଳାନ୍ତି ନାହିଁ ଯାହା ଆପଣଙ୍କ ଫାଇଲ୍, ପାସୱାର୍ଡ କିମ୍ବା ବ୍ୟବହାର ତଥ୍ୟ ଗ୍ରହଣ କରେ।

## ତଥ୍ୟ ଯାହା ବିକାଶକାରୀ ସଂଗ୍ରହ କରନ୍ତି ନାହିଁ

ଆପ୍‌ରେ ବିଜ୍ଞାପନ, ବିଶ୍ଳେଷଣ, କ୍ରାସ୍ ରିପୋର୍ଟ କିମ୍ବା ଟ୍ରାକିଂ SDK ନାହିଁ। ବିକାଶକାରୀ ବ୍ୟକ୍ତିଗତ ତଥ୍ୟ ସଂଗ୍ରହ, ବିକ୍ରୟ କିମ୍ବା ଅଂଶୀଦାର କରନ୍ତି ନାହିଁ।

## ଆପଣଙ୍କ କମ୍ପ୍ୟୁଟରରେ ସଂରକ୍ଷିତ ତଥ୍ୟ

### କାର୍ଯ୍ୟ ଏବଂ ସେଟିଂସ୍

କାର୍ଯ୍ୟ ପରିଭାଷା କେବଳ ଏହି କମ୍ପ୍ୟୁଟରରେ ସଂରକ୍ଷିତ ହୁଏ। କାର୍ଯ୍ୟରେ ଫୋଲ୍ଡର୍ ପଥ, ସମୟସୂଚୀ, ସଂରକ୍ଷଣ ସେଟିଂସ୍ ଏବଂ ଆପଣ ଟାଇପ୍ କରିଥିବା ପାସୱାର୍ଡ କିମ୍ବା ଟୋକେନ୍ ଥାଇପାରେ। ପାସୱାର୍ଡ ଏବଂ ସଂରକ୍ଷଣ ଗୁପ୍ତ ତଥ୍ୟ ସଞ୍ଚୟ ପୂର୍ବରୁ ଏହି କମ୍ପ୍ୟୁଟରରେ ଏନ୍‌କ୍ରିପ୍ଟ ହୁଏ ଏବଂ କେବଳ ଏହି କମ୍ପ୍ୟୁଟରରେ ପଢ଼ାଯାଇପାରେ। ଏହି ମୂଲ୍ୟଗୁଡ଼ିକ ବିକାଶକାରୀଙ୍କୁ ପଠାଯାଏ ନାହିଁ।

- Windows କାର୍ଯ୍ୟ: `%AppData%\BUtil Backup Tasks`
- Linux କାର୍ଯ୍ୟ: `~/.config/BUtil Backup Tasks`
- Windows ସେଟିଂସ୍ (ଥିମ୍ ଏବଂ ଲାଇସେନ୍ସ କିମ୍ବା ଗୋପନୀୟତା ପାଇଁ ଶେଷରେ ବଛା ଭାଷା ସହ): `%AppData%\BUtil\Settings\v1`
- Linux ସେଟିଂସ୍: `~/.config/BUtil/Settings/v1`
- Windows କାର୍ଯ୍ୟ ସ୍ଥିତି: `%AppData%\BUtil\States`
- Linux କାର୍ଯ୍ୟ ସ୍ଥିତି: `~/.config/BUtil/States`
- Windows ମିଡ଼ିଆ ଆମଦାନି ସ୍ଥିତି: `%AppData%\BUtil Backup Tasks - States`
- Linux ମିଡ଼ିଆ ଆମଦାନି ସ୍ଥିତି: `~/.config/BUtil Backup Tasks - States`

### ଆପଣ ବାଛିଥିବା ଫାଇଲ୍

ବ୍ୟାକଅପ୍, ସିଙ୍କ୍, ପୁନରୁଦ୍ଧାର ଏବଂ ଆମଦାନି ଆପଣ ବାଛିଥିବା ଫୋଲ୍ଡର୍ ପଢ଼େ ଏବଂ ଲେଖେ। ସେହି ଫାଇଲ୍ ଏହି କମ୍ପ୍ୟୁଟରରେ କିମ୍ବା ଆପଣ ସେଟ୍ କରିଥିବା ସଂରକ୍ଷଣରେ ରହେ। ଆପ୍ ସେଗୁଡ଼ିକୁ ବିକାଶକାରୀଙ୍କୁ ପଠାଏ ନାହିଁ।

### ଲଗ୍

ନିଦାନ ଲଗ୍ କେବଳ ଏହି କମ୍ପ୍ୟୁଟରରେ ଲେଖାଯାଏ:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

ସେହି ଫାଇଲ୍ କୌଣସି ସ୍ଥାନକୁ ପଠାଯାଏ ନାହିଁ।

ଆପଣଙ୍କ ତଥ୍ୟ ସଂରକ୍ଷଣ ପାଇଁ ବିକାଶକାରୀଙ୍କ ସର୍ଭର ବ୍ୟବହାର ହୁଏ ନାହିଁ।

## ନେଟୱାର୍କ ବ୍ୟବହାର

### ଆପଣ ସେଟ୍ କରିଥିବା ଗନ୍ତବ୍ୟ

କାର୍ଯ୍ୟ ଚାଲିବା ସମୟରେ ଆପ୍ କେବଳ ଆପଣ ନିର୍ଦ୍ଧାରିତ ସ୍ଥାନ ସହିତ ଯୋଡ଼େ। ଏହା ସ୍ଥାନୀୟ ଫୋଲ୍ଡର୍ କିମ୍ବା ଆପଣ ପ୍ରବେଶ କରିଥିବା ସର୍ଭର ହୋଇପାରେ: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-ସୁସଙ୍ଗତ ସଂରକ୍ଷଣ କିମ୍ବା Azure Blob Storage। ଫାଇଲ୍ ନାମ, ବିଷୟବସ୍ତୁ ଏବଂ ଆପଣ ପ୍ରବେଶ କରିଥିବା ପରିଚୟପତ୍ର କାର୍ଯ୍ୟ ଚାଲିବା ପାଇଁ ସେହି ସର୍ଭରକୁ ଯାଏ। ପ୍ରତ୍ୟେକ ସେବାର ନିଜ ଗୋପନୀୟତା ନୀତି ଅଛି। ବିକାଶକାରୀ ଏହି ଟ୍ରାଫିକ୍ ପାଆନ୍ତି ନାହିଁ।

BUtil Server ଏହି କମ୍ପ୍ୟୁଟରରେ ଶୁଣିପାରେ ଯାହାଫଳରେ ଆପଣ ସେଟ୍ କରିଥିବା BUtil କ୍ଲାଏଣ୍ଟ ଫାଇଲ୍ ପଠାଇପାରିବ। ସେହି ଟ୍ରାଫିକ୍ ଆପଣ ସେଟ୍ କରିଥିବା କମ୍ପ୍ୟୁଟର ମଧ୍ୟରେ ରହେ।

### ଅଦ୍ୟତନ ଯାଞ୍ଚ

Store ବାହାର ବିଲ୍ଡ ନବୀନତମ GitHub ରିଲିଜ୍ ମାଗିପାରେ:

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) ସାଧାରଣ HTTPS ଅନୁରୋଧ ପାଏ (IP ଠିକଣା, user-agent, ସମୟ)। ବିକାଶକାରୀ ଏହି ଟ୍ରାଫିକ୍ ପାଆନ୍ତି ନାହିଁ।

Microsoft Store ରୁ ସଂସ୍ଥାପନ ଏହି ଯାଞ୍ଚ ବ୍ୟବହାର କରେ ନାହିଁ; ଅଦ୍ୟତନ Store ଦେଇଥାଏ।

### ଆପଣ ଖୋଲିଥିବା ଲିଙ୍କ

ଆପ୍ ଏହି ପୃଷ୍ଠାଗୁଡ଼ିକ ସିଷ୍ଟମ୍ ବ୍ରାଉଜରରେ ଖୋଲିପାରେ। ସେହି ସାଇଟ୍‌ଗୁଡ଼ିକର ନିଜ ଗୋପନୀୟତା ନୀତି ଅଛି:

- ପ୍ରକଳ୍ପ ମୂଳପୃଷ୍ଠା: [github.com/drweb86/butil](https://github.com/drweb86/butil)
- ନବୀନତମ ରିଲିଜ୍: [github.com/drweb86/butil/releases/latest](https://github.com/drweb86/butil/releases/latest)
- ଫାଇଲ୍ ପ୍ୟାଟର୍ନ ସହାୟତା: [learn.microsoft.com file globbing](https://learn.microsoft.com/en-us/dotnet/core/extensions/file-globbing#pattern-formats)
- ତାରିଖ ଫର୍ମାଟ୍ ସହାୟତା: [learn.microsoft.com custom date and time format strings](https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings)
- ଆଇକନ୍ ଉତ୍ସ: [github.com/drweb86/butil Icons](https://github.com/drweb86/butil/blob/master/help/Icons.md)

ଲାଇସେନ୍ସ ଏବଂ ଏହି ଗୋପନୀୟତା ନୀତି ଆପ୍ ଭିତରେ ଦେଖାଯାଏ। ସେଗୁଡ଼ିକ ୱେବ୍ ପୃଷ୍ଠା ଭାବେ ଖୋଲେ ନାହିଁ।

## ସମୟସୂଚୀ

Windows ରେ ଆପଣ ସାଇନ୍-ଇନ୍ ସମୟରେ କିମ୍ବା ସାପ୍ତାହିକ ସମୟସୂଚୀରେ କାର୍ଯ୍ୟ ଚଳାଇପାରିବେ। ଆପ୍ ଏହାକୁ Windows Task Scheduler ରେ `BUtil` ରୁ ଆରମ୍ଭ ହେଉଥିବା ନାମରେ ପଞ୍ଜିକୃତ କରେ। ଏହା କେବଳ ଏହି ଆପ୍ ଆପଣଙ୍କ କମ୍ପ୍ୟୁଟରରେ ଆରମ୍ଭ କରେ।

## ଶିଶୁ

ଆପ୍ ବ୍ୟାକଅପ୍ ଏବଂ ଫାଇଲ୍ ସିଙ୍କ୍ ଉପକରଣ। ଏହା ୧୩ ବର୍ଷରୁ କମ୍ ଶିଶୁଙ୍କ ପାଇଁ ନୁହେଁ।
