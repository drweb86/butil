# Maxfiylik siyosati

Oxirgi yangilanish: 2026-yil 25-sentabr

**BUtil** by Siarhei Kuchuk

Ilova nomi: BUtil
Ishlab chiquvchi nomi: Siarhei Kuchuk

BUtil ushbu kompyuterdagi fayllarni zaxiralaydi, sinxronlaydi va tiklaydi. U media import qilishi, jild ulashishi yoki fayllarni siz sozlagan serverga yuklashi mumkin. Ishlab chiquvchi hisobini yaratmaydi. Ishlab chiquvchi fayllaringiz, parollaringiz yoki foydalanish ma’lumotlaringizni qabul qiladigan server ishlatmaydi.

## Ishlab chiquvchi yig‘maydigan ma’lumotlar

Ilovada reklama, tahlil, nosozlik hisobotlari yoki kuzatuv SDK yo‘q. Ishlab chiquvchi shaxsiy ma’lumotlarni yig‘maydi, sotmaydi va ulashmaydi.

## Kompyuteringizda saqlanadigan ma’lumotlar

### Vazifalar va sozlamalar

Vazifa ta’riflari faqat shu kompyuterda saqlanadi. Vazifa jild yo‘llari, jadval, saqlash sozlamalari hamda siz kiritgan parol yoki tokenlarni o‘z ichiga olishi mumkin. Parollar va saqlash sirlari saqlanishidan oldin shu kompyuterda shifrlanadi va faqat shu kompyuterda o‘qiladi. Bu qiymatlar ishlab chiquvchiga yuborilmaydi.

- Windows vazifalari: `%AppData%\BUtil Backup Tasks`
- Linux vazifalari: `~/.config/BUtil Backup Tasks`
- Windows sozlamalari (mavzu hamda litsenziya yoki maxfiylik uchun oxirgi tanlangan til bilan): `%AppData%\BUtil\Settings\v1`
- Linux sozlamalari: `~/.config/BUtil/Settings/v1`
- Windows vazifa holati: `%AppData%\BUtil\States`
- Linux vazifa holati: `~/.config/BUtil/States`
- Windows media importi holati: `%AppData%\BUtil Backup Tasks - States`
- Linux media importi holati: `~/.config/BUtil Backup Tasks - States`

### Siz tanlagan fayllar

Zaxira, sinxronlash, tiklash va import siz tanlagan jildlarni o‘qiydi va yozadi. Bu fayllar shu kompyuterda yoki siz sozlagan saqlash joyida qoladi. Ilova ularni ishlab chiquvchiga yuklamaydi.

### Jurnallar

Diagnostika jurnallari faqat shu kompyuterga yoziladi:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

Bu fayllar hech qayerga yuborilmaydi.

Ma’lumotlaringizni saqlash uchun ishlab chiquvchi serveri ishlatilmaydi.

## Tarmoqdan foydalanish

### Siz sozlaydigan manzillar

Vazifa ishlaganda ilova faqat siz belgilagan joyga ulanadi. Bu mahalliy jild yoki siz kiritgan server bo‘lishi mumkin: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3 bilan mos saqlash yoki Azure Blob Storage. Fayl nomlari, fayl mazmuni va kiritgan hisob ma’lumotlaringiz vazifa ishlashi uchun o‘sha serverga yuboriladi. Bu xizmatlarning har birining o‘z maxfiylik siyosati bor. Ishlab chiquvchi bu trafikni olmaydi.

BUtil Server siz sozlagan BUtil mijozi fayl yubora olishi uchun shu kompyuterda tinglashi mumkin. Bu trafik siz sozlagan kompyuterlar o‘rtasida qoladi.
