# ਗੋਪਨੀਯਤਾ ਨੀਤੀ

ਆਖਰੀ ਅੱਪਡੇਟ: 25 ਸਤੰਬਰ 2026

**BUtil** by Siarhei Kuchuk

ਐਪ ਦਾ ਨਾਮ: BUtil
ਡਿਵੈਲਪਰ ਦਾ ਨਾਮ: Siarhei Kuchuk

BUtil ਇਸ ਕੰਪਿਊਟਰ ਉੱਤੇ ਫ਼ਾਈਲਾਂ ਦਾ ਬੈਕਅੱਪ ਲੈਂਦਾ ਹੈ, ਉਹਨਾਂ ਨੂੰ ਸਿੰਕ ਕਰਦਾ ਹੈ ਅਤੇ ਮੁੜ ਬਹਾਲ ਕਰਦਾ ਹੈ। ਇਹ ਮੀਡੀਆ ਆਯਾਤ ਕਰ ਸਕਦਾ ਹੈ, ਫੋਲਡਰ ਸਾਂਝਾ ਕਰ ਸਕਦਾ ਹੈ, ਜਾਂ ਤੁਹਾਡੇ ਸੈੱਟ ਕੀਤੇ ਸਰਵਰ ਉੱਤੇ ਫ਼ਾਈਲਾਂ ਅੱਪਲੋਡ ਕਰ ਸਕਦਾ ਹੈ। ਇਹ ਡਿਵੈਲਪਰ ਖਾਤਾ ਨਹੀਂ ਬਣਾਉਂਦਾ। ਡਿਵੈਲਪਰ ਅਜਿਹਾ ਸਰਵਰ ਨਹੀਂ ਚਲਾਉਂਦਾ ਜੋ ਤੁਹਾਡੀਆਂ ਫ਼ਾਈਲਾਂ, ਪਾਸਵਰਡ ਜਾਂ ਵਰਤੋਂ ਡਾਟਾ ਲੈਂਦਾ ਹੋਵੇ।

## ਡਾਟਾ ਜੋ ਡਿਵੈਲਪਰ ਇਕੱਠਾ ਨਹੀਂ ਕਰਦਾ

ਐਪ ਵਿੱਚ ਇਸ਼ਤਿਹਾਰ, ਵਿਸ਼ਲੇਸ਼ਣ, ਕ੍ਰੈਸ਼ ਰਿਪੋਰਟ ਜਾਂ ਟ੍ਰੈਕਿੰਗ SDK ਨਹੀਂ ਹਨ। ਡਿਵੈਲਪਰ ਨਿੱਜੀ ਡਾਟਾ ਇਕੱਠਾ, ਵੇਚਦਾ ਜਾਂ ਸਾਂਝਾ ਨਹੀਂ ਕਰਦਾ।

## ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ ਉੱਤੇ ਸੰਭਾਲਿਆ ਡਾਟਾ

### ਕੰਮ ਅਤੇ ਸੈਟਿੰਗਾਂ

ਕੰਮ ਦੀਆਂ ਪਰਿਭਾਸ਼ਾਵਾਂ ਸਿਰਫ਼ ਇਸ ਕੰਪਿਊਟਰ ਉੱਤੇ ਸੰਭਾਲੀਆਂ ਜਾਂਦੀਆਂ ਹਨ। ਕੰਮ ਵਿੱਚ ਫੋਲਡਰ ਮਾਰਗ, ਸਮਾਂ-ਸਾਰਣੀ, ਸਟੋਰੇਜ ਸੈਟਿੰਗਾਂ ਅਤੇ ਤੁਹਾਡੇ ਲਿਖੇ ਪਾਸਵਰਡ ਜਾਂ ਟੋਕਨ ਹੋ ਸਕਦੇ ਹਨ। ਪਾਸਵਰਡ ਅਤੇ ਸਟੋਰੇਜ ਰਾਜ਼ ਸੰਭਾਲਣ ਤੋਂ ਪਹਿਲਾਂ ਇਸ ਕੰਪਿਊਟਰ ਉੱਤੇ ਇਨਕ੍ਰਿਪਟ ਹੁੰਦੇ ਹਨ ਅਤੇ ਸਿਰਫ਼ ਇਸ ਕੰਪਿਊਟਰ ਉੱਤੇ ਪੜ੍ਹੇ ਜਾ ਸਕਦੇ ਹਨ। ਇਹ ਮੁੱਲ ਡਿਵੈਲਪਰ ਨੂੰ ਨਹੀਂ ਭੇਜੇ ਜਾਂਦੇ।

- Windows ਕੰਮ: `%AppData%\BUtil Backup Tasks`
- Linux ਕੰਮ: `~/.config/BUtil Backup Tasks`
- Windows ਸੈਟਿੰਗਾਂ (ਥੀਮ ਅਤੇ ਲਾਇਸੰਸ ਜਾਂ ਗੋਪਨੀਯਤਾ ਲਈ ਆਖਰੀ ਚੁਣੀ ਭਾਸ਼ਾ ਸਮੇਤ): `%AppData%\BUtil\Settings\v1`
- Linux ਸੈਟਿੰਗਾਂ: `~/.config/BUtil/Settings/v1`
- Windows ਕੰਮ ਦੀ ਸਥਿਤੀ: `%AppData%\BUtil\States`
- Linux ਕੰਮ ਦੀ ਸਥਿਤੀ: `~/.config/BUtil/States`
- Windows ਮੀਡੀਆ ਆਯਾਤ ਸਥਿਤੀ: `%AppData%\BUtil Backup Tasks - States`
- Linux ਮੀਡੀਆ ਆਯਾਤ ਸਥਿਤੀ: `~/.config/BUtil Backup Tasks - States`

### ਤੁਹਾਡੀਆਂ ਚੁਣੀਆਂ ਫ਼ਾਈਲਾਂ

ਬੈਕਅੱਪ, ਸਿੰਕ, ਮੁੜ ਬਹਾਲੀ ਅਤੇ ਆਯਾਤ ਤੁਹਾਡੇ ਚੁਣੇ ਫੋਲਡਰ ਪੜ੍ਹਦੇ ਅਤੇ ਲਿਖਦੇ ਹਨ। ਉਹ ਫ਼ਾਈਲਾਂ ਇਸ ਕੰਪਿਊਟਰ ਉੱਤੇ ਜਾਂ ਤੁਹਾਡੇ ਸੈੱਟ ਕੀਤੇ ਸਟੋਰੇਜ ਉੱਤੇ ਰਹਿੰਦੀਆਂ ਹਨ। ਐਪ ਉਹਨਾਂ ਨੂੰ ਡਿਵੈਲਪਰ ਨੂੰ ਨਹੀਂ ਭੇਜਦੀ।

### ਲਾਗ

ਨਿਦਾਨ ਲਾਗ ਸਿਰਫ਼ ਇਸ ਕੰਪਿਊਟਰ ਉੱਤੇ ਲਿਖੀਆਂ ਜਾਂਦੀਆਂ ਹਨ:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

ਉਹ ਫ਼ਾਈਲਾਂ ਕਿਤੇ ਨਹੀਂ ਭੇਜੀਆਂ ਜਾਂਦੀਆਂ।

ਤੁਹਾਡਾ ਡਾਟਾ ਸੰਭਾਲਣ ਲਈ ਡਿਵੈਲਪਰ ਦਾ ਸਰਵਰ ਵਰਤਿਆ ਨਹੀਂ ਜਾਂਦਾ।

## ਨੈੱਟਵਰਕ ਵਰਤੋਂ

### ਤੁਹਾਡੇ ਸੈੱਟ ਕੀਤੇ ਟਿਕਾਣੇ

ਜਦੋਂ ਕੋਈ ਕੰਮ ਚੱਲਦਾ ਹੈ, ਐਪ ਸਿਰਫ਼ ਤੁਹਾਡੇ ਨਿਰਧਾਰਤ ਥਾਂ ਨਾਲ ਜੁੜਦੀ ਹੈ। ਇਹ ਸਥਾਨਕ ਫੋਲਡਰ ਜਾਂ ਤੁਹਾਡਾ ਦਰਜ ਕੀਤਾ ਸਰਵਰ ਹੋ ਸਕਦਾ ਹੈ: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-ਅਨੁਕੂਲ ਸਟੋਰੇਜ ਜਾਂ Azure Blob Storage। ਫ਼ਾਈਲ ਨਾਮ, ਸਮੱਗਰੀ ਅਤੇ ਤੁਹਾਡੇ ਦਰਜ ਕੀਤੇ ਪ੍ਰਮਾਣ-ਪੱਤਰ ਉਸ ਸਰਵਰ ਨੂੰ ਭੇਜੇ ਜਾਂਦੇ ਹਨ ਤਾਂ ਜੋ ਕੰਮ ਚੱਲ ਸਕੇ। ਹਰ ਸੇਵਾ ਦੀ ਆਪਣੀ ਗੋਪਨੀਯਤਾ ਨੀਤੀ ਹੈ। ਡਿਵੈਲਪਰ ਨੂੰ ਇਹ ਟ੍ਰੈਫ਼ਿਕ ਨਹੀਂ ਮਿਲਦਾ।

BUtil Server ਇਸ ਕੰਪਿਊਟਰ ਉੱਤੇ ਸੁਣ ਸਕਦਾ ਹੈ ਤਾਂ ਜੋ ਤੁਹਾਡਾ ਸੈੱਟ ਕੀਤਾ BUtil ਕਲਾਇੰਟ ਫ਼ਾਈਲਾਂ ਭੇਜ ਸਕੇ। ਉਹ ਟ੍ਰੈਫ਼ਿਕ ਤੁਹਾਡੇ ਸੈੱਟ ਕੀਤੇ ਕੰਪਿਊਟਰਾਂ ਵਿਚਕਾਰ ਰਹਿੰਦਾ ਹੈ।

### ਅੱਪਡੇਟ ਜਾਂਚ

Store ਤੋਂ ਬਾਹਰ ਦੀਆਂ ਬਿਲਡਾਂ ਨਵੀਨਤਮ GitHub ਰਿਲੀਜ਼ ਮੰਗ ਸਕਦੀਆਂ ਹਨ:

`https://api.github.com/repos/drweb86/butil/releases/latest`

GitHub (Microsoft) ਨੂੰ ਆਮ HTTPS ਬੇਨਤੀ ਮਿਲਦੀ ਹੈ (IP ਪਤਾ, user-agent, ਸਮਾਂ)। ਡਿਵੈਲਪਰ ਨੂੰ ਇਹ ਟ੍ਰੈਫ਼ਿਕ ਨਹੀਂ ਮਿਲਦਾ।

Microsoft Store ਤੋਂ ਇੰਸਟਾਲ ਇਹ ਜਾਂਚ ਨਹੀਂ ਵਰਤਦੇ; ਅੱਪਡੇਟ Store ਦਿੰਦਾ ਹੈ।

## ਸਮਾਂ-ਸਾਰਣੀ

Windows ਉੱਤੇ ਤੁਸੀਂ ਸਾਈਨ-ਇਨ ਵੇਲੇ ਜਾਂ ਹਫ਼ਤਾਵਾਰੀ ਸਾਰਣੀ ਉੱਤੇ ਕੰਮ ਚਲਾ ਸਕਦੇ ਹੋ। ਐਪ ਇਸਨੂੰ Windows Task Scheduler ਵਿੱਚ ਅਜਿਹੇ ਨਾਮ ਨਾਲ ਰਜਿਸਟਰ ਕਰਦੀ ਹੈ ਜੋ `BUtil` ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ। ਇਹ ਸਿਰਫ਼ ਇਹ ਐਪ ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ ਉੱਤੇ ਸ਼ੁਰੂ ਕਰਦੀ ਹੈ।
