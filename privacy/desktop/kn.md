# ಗೌಪ್ಯತೆ ನೀತಿ

ಕೊನೆಯ ನವೀಕರಣ: 25 ಸೆಪ್ಟೆಂಬರ್ 2026

**BUtil** by Siarhei Kuchuk

ಅಪ್ಲಿಕೇಶನ್ ಹೆಸರು: BUtil
ಅಭಿವೃದ್ಧಿಕಾರರ ಹೆಸರು: Siarhei Kuchuk

BUtil ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಫೈಲ್‌ಗಳನ್ನು ಬ್ಯಾಕಪ್ ಮಾಡುತ್ತದೆ, ಸಿಂಕ್ ಮಾಡುತ್ತದೆ ಮತ್ತು ಮರುಸ್ಥಾಪಿಸುತ್ತದೆ. ಇದು ಮಾಧ್ಯಮವನ್ನು ಆಮದು ಮಾಡಬಹುದು, ಫೋಲ್ಡರ್ ಹಂಚಬಹುದು ಅಥವಾ ನೀವು ಹೊಂದಿಸಿದ ಸರ್ವರ್‌ಗೆ ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಬಹುದು. ಇದು ಅಭಿವೃದ್ಧಿಕಾರರ ಖಾತೆಯನ್ನು ರಚಿಸುವುದಿಲ್ಲ. ಅಭಿವೃದ್ಧಿಕಾರರು ನಿಮ್ಮ ಫೈಲ್‌ಗಳು, ಪಾಸ್‌ವರ್ಡ್‌ಗಳು ಅಥವಾ ಬಳಕೆ ಡೇಟಾವನ್ನು ಸ್ವೀಕರಿಸುವ ಸರ್ವರ್ ನಡೆಸುವುದಿಲ್ಲ.

## ಅಭಿವೃದ್ಧಿಕಾರರು ಸಂಗ್ರಹಿಸದ ಡೇಟಾ

ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ಜಾಹೀರಾತು, ವಿಶ್ಲೇಷಣೆ, ಕ್ರ್ಯಾಶ್ ವರದಿ ಅಥವಾ ಟ್ರ್ಯಾಕಿಂಗ್ SDK ಇಲ್ಲ. ಅಭಿವೃದ್ಧಿಕಾರರು ವೈಯಕ್ತಿಕ ಡೇಟಾವನ್ನು ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ, ಮಾರಾಟ ಮಾಡುವುದಿಲ್ಲ ಅಥವಾ ಹಂಚುವುದಿಲ್ಲ.

## ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಸಂಗ್ರಹವಾಗಿರುವ ಡೇಟಾ

### ಕಾರ್ಯಗಳು ಮತ್ತು ಸೆಟ್ಟಿಂಗ್‌ಗಳು

ಕಾರ್ಯದ ವ್ಯಾಖ್ಯಾನಗಳು ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಮಾತ್ರ ಸಂಗ್ರಹವಾಗುತ್ತವೆ. ಕಾರ್ಯದಲ್ಲಿ ಫೋಲ್ಡರ್ ಮಾರ್ಗಗಳು, ವೇಳಾಪಟ್ಟಿ, ಸಂಗ್ರಹಣೆ ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು ನೀವು ಟೈಪ್ ಮಾಡಿದ ಪಾಸ್‌ವರ್ಡ್ ಅಥವಾ ಟೋಕನ್‌ಗಳು ಇರಬಹುದು. ಪಾಸ್‌ವರ್ಡ್ ಮತ್ತು ಸಂಗ್ರಹಣೆ ರಹಸ್ಯಗಳನ್ನು ಉಳಿಸುವ ಮೊದಲು ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಗೂಢಲಿಪೀಕರಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಮಾತ್ರ ಓದಬಹುದು. ಈ ಮೌಲ್ಯಗಳನ್ನು ಅಭಿವೃದ್ಧಿಕಾರರಿಗೆ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.

- Windows ಕಾರ್ಯಗಳು: `%AppData%\BUtil Backup Tasks`
- Linux ಕಾರ್ಯಗಳು: `~/.config/BUtil Backup Tasks`
- Windows ಸೆಟ್ಟಿಂಗ್‌ಗಳು (ಥೀಮ್ ಮತ್ತು ಪರವಾನಗಿ ಅಥವಾ ಗೌಪ್ಯತೆಗೆ ಕೊನೆಯದಾಗಿ ಆಯ್ಕೆಮಾಡಿದ ಭಾಷೆ ಸೇರಿ): `%AppData%\BUtil\Settings\v1`
- Linux ಸೆಟ್ಟಿಂಗ್‌ಗಳು: `~/.config/BUtil/Settings/v1`
- Windows ಕಾರ್ಯ ಸ್ಥಿತಿ: `%AppData%\BUtil\States`
- Linux ಕಾರ್ಯ ಸ್ಥಿತಿ: `~/.config/BUtil/States`
- Windows ಮಾಧ್ಯಮ ಆಮದು ಸ್ಥಿತಿ: `%AppData%\BUtil Backup Tasks - States`
- Linux ಮಾಧ್ಯಮ ಆಮದು ಸ್ಥಿತಿ: `~/.config/BUtil Backup Tasks - States`

### ನೀವು ಆಯ್ಕೆಮಾಡಿದ ಫೈಲ್‌ಗಳು

ಬ್ಯಾಕಪ್, ಸಿಂಕ್, ಮರುಸ್ಥಾಪನೆ ಮತ್ತು ಆಮದು ನೀವು ಆಯ್ಕೆಮಾಡಿದ ಫೋಲ್ಡರ್‌ಗಳನ್ನು ಓದುತ್ತವೆ ಮತ್ತು ಬರೆಯುತ್ತವೆ. ಆ ಫೈಲ್‌ಗಳು ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಅಥವಾ ನೀವು ಹೊಂದಿಸಿದ ಸಂಗ್ರಹಣೆಯಲ್ಲಿ ಉಳಿಯುತ್ತವೆ. ಅಪ್ಲಿಕೇಶನ್ ಅವುಗಳನ್ನು ಅಭಿವೃದ್ಧಿಕಾರರಿಗೆ ಕಳುಹಿಸುವುದಿಲ್ಲ.

### ಲಾಗ್‌ಗಳು

ರೋಗನಿರ್ಣಯ ಲಾಗ್‌ಗಳನ್ನು ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಮಾತ್ರ ಬರೆಯಲಾಗುತ್ತದೆ:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

ಆ ಫೈಲ್‌ಗಳನ್ನು ಎಲ್ಲಿಯೂ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.

ನಿಮ್ಮ ಡೇಟಾವನ್ನು ಸಂಗ್ರಹಿಸಲು ಅಭಿವೃದ್ಧಿಕಾರರ ಸರ್ವರ್ ಬಳಸಲಾಗುವುದಿಲ್ಲ.

## ನೆಟ್‌ವರ್ಕ್ ಬಳಕೆ

### ನೀವು ಹೊಂದಿಸಿದ ಗಮ್ಯಸ್ಥಾನಗಳು

ಕಾರ್ಯ ನಡೆಯುವಾಗ ಅಪ್ಲಿಕೇಶನ್ ನೀವು ನಿಗದಿಪಡಿಸಿದ ಸ್ಥಳಕ್ಕೆ ಮಾತ್ರ ಸಂಪರ್ಕಿಸುತ್ತದೆ. ಅದು ಸ್ಥಳೀಯ ಫೋಲ್ಡರ್ ಅಥವಾ ನೀವು ನಮೂದಿಸಿದ ಸರ್ವರ್ ಆಗಿರಬಹುದು: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-ಹೊಂದಾಣಿಕೆಯ ಸಂಗ್ರಹಣೆ ಅಥವಾ Azure Blob Storage. ಫೈಲ್ ಹೆಸರುಗಳು, ವಿಷಯ ಮತ್ತು ನೀವು ನಮೂದಿಸಿದ ರುಜುವಾತುಗಳನ್ನು ಕಾರ್ಯ ನಡೆಯಲು ಆ ಸರ್ವರ್‌ಗೆ ಕಳುಹಿಸಲಾಗುತ್ತದೆ. ಪ್ರತಿ ಸೇವೆಗೆ ತನ್ನದೇ ಗೌಪ್ಯತೆ ನೀತಿ ಇದೆ. ಅಭಿವೃದ್ಧಿಕಾರರು ಆ ಟ್ರಾಫಿಕ್ ಪಡೆಯುವುದಿಲ್ಲ.

BUtil Server ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಕೇಳಬಹುದು ಇದರಿಂದ ನೀವು ಹೊಂದಿಸಿದ BUtil ಕ್ಲೈಂಟ್ ಫೈಲ್‌ಗಳನ್ನು ಕಳುಹಿಸಬಹುದು. ಆ ಟ್ರಾಫಿಕ್ ನೀವು ಹೊಂದಿಸಿದ ಕಂಪ್ಯೂಟರ್‌ಗಳ ನಡುವೆ ಉಳಿಯುತ್ತದೆ.
