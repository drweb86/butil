**BUtil** by Siarhei Kuchuk

د اپلیکیشن نوم: BUtil
د پراختیا کوونکي نوم: Siarhei Kuchuk

BUtil په دې کمپیوټر کې د فایلونو بیک اپ اخلي، همغږي کوي او بېرته راولي. دا کولی شي رسنۍ راوړي، فولډر شریک کړي، یا فایلونه هغه سرور ته پورته کړي چې تاسو یې ټاکئ. دا د پراختیا کوونکي حساب نه جوړوي. پراختیا کوونکی داسې سرور نه چلوي چې ستاسو فایلونه، پاسورډونه یا د کارونې معلومات ترلاسه کړي.

## هغه معلومات چې پراختیا کوونکی یې نه راټولوي

اپلیکیشن کې اعلانونه، تحلیل، د خرابۍ راپورونه یا تعقیبي SDK نشته. پراختیا کوونکی شخصي معلومات نه راټولوي، نه یې پلوري او نه یې شریکوي.

## په کمپیوټر کې خوندي معلومات

### دندې او تنظیمات

د دندو تعریفونه یوازې په دې کمپیوټر کې خوندي کېږي. یوه دنده کولی شي د فولډر لارې، مهالویش، د ذخیره کولو تنظیمات او هغه پاسورډونه یا ټوکنونه ولري چې تاسو یې لیکئ. پاسورډونه او د ذخیره کولو رازونه له خوندي کولو مخکې په دې کمپیوټر کې کوډ کېږي او یوازې په دې کمپیوټر کې لوستل کېږي. دا ارزښتونه پراختیا کوونکي ته نه پورته کېږي.

- د Windows دندې: `%AppData%\BUtil Backup Tasks`
- د Linux دندې: `~/.config/BUtil Backup Tasks`
- د Windows تنظیمات (موضوع او هغه ژبه چې وروستی ځل د جواز یا رازدارۍ لپاره ټاکل شوې): `%AppData%\BUtil\Settings\v1`
- د Linux تنظیمات: `~/.config/BUtil/Settings/v1`
- د Windows دندو حالت: `%AppData%\BUtil\States`
- د Linux دندو حالت: `~/.config/BUtil/States`
- د Windows د رسنیو د راوړلو حالت: `%AppData%\BUtil Backup Tasks - States`
- د Linux د رسنیو د راوړلو حالت: `~/.config/BUtil Backup Tasks - States`

### هغه فایلونه چې تاسو یې ټاکئ

بیک اپ، همغږي، بېرته راوړل او راوړل هغه فولډرونه لولي او لیکي چې تاسو یې ټاکئ. دا فایلونه په دې کمپیوټر یا په هغه ذخیره کې پاتې کېږي چې تاسو یې ټاکئ. اپلیکیشن یې پراختیا کوونکي ته نه پورته کوي.

### لاګونه

تشخیصي لاګونه یوازې په دې کمپیوټر کې لیکل کېږي:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

دا فایلونه هیڅ ځای ته نه لېږل کېږي.

ستاسو د معلوماتو د ساتلو لپاره د پراختیا کوونکي سرور نه کارول کېږي.

## د شبکې کارونه

### هغه ځایونه چې تاسو یې ټاکئ

کله چې دنده روانه وي، اپلیکیشن یوازې هغه ځای سره نښلي چې تاسو یې ټاکئ. دا کولی شي ځایي فولډر یا هغه سرور وي چې تاسو یې لیکئ: FTP، FTPS، SFTP، WebDAV، SMB، NFS، له S3 سره سمون لرونکې ذخیره یا Azure Blob Storage. د فایل نومونه، منځپانګه او هغه اسناد چې تاسو یې لیکلي دي، دې سرور ته لېږل کېږي تر څو دنده وچلېږي. د دې خدمتونو هر یو خپله رازداري پالیسي لري. پراختیا کوونکی دا ترافیک نه ترلاسه کوي.

BUtil Server کولی شي په دې کمپیوټر کې اورېږي تر څو ستاسو ټاکلی BUtil پیرودونکی فایلونه ولېږي. دا ترافیک د هغو کمپیوټرونو ترمنځ پاتې کېږي چې تاسو یې جوړوئ.
