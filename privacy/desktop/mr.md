# गोपनीयता धोरण

शेवटचे अद्यतन: 25 सप्टेंबर 2026

**BUtil** by Siarhei Kuchuk

अनुप्रयोगाचे नाव: BUtil
विकासकाचे नाव: Siarhei Kuchuk

BUtil या संगणकावरील फाइल्सचा बॅकअप घेते, समक्रमित करते आणि पुनर्संचयित करते. ते माध्यम आयात करू शकते, फोल्डर शेअर करू शकते किंवा तुम्ही सेट केलेल्या सर्व्हरवर फाइल्स अपलोड करू शकते. ते विकासक खाते तयार करत नाही. विकासक असा सर्व्हर चालवत नाही जो तुमच्या फाइल्स, पासवर्ड किंवा वापर डेटा प्राप्त करतो.

## विकासक गोळा न करणारा डेटा

अ‍ॅपमध्ये जाहिराती, विश्लेषण, क्रॅश अहवाल किंवा ट्रॅकिंग SDK नाहीत. विकासक वैयक्तिक डेटा गोळा, विक्री किंवा शेअर करत नाही.

## तुमच्या संगणकावर साठवलेला डेटा

### कार्ये आणि सेटिंग्ज

कार्य व्याख्या फक्त या संगणकावर साठवल्या जातात. कार्यात फोल्डर मार्ग, वेळापत्रक, साठवण सेटिंग्ज आणि तुम्ही टाइप केलेले पासवर्ड किंवा टोकन असू शकतात. पासवर्ड आणि साठवण गुपिते जतन करण्यापूर्वी या संगणकावर एन्क्रिप्ट केली जातात आणि फक्त या संगणकावर वाचली जाऊ शकतात. ही मूल्ये विकासकाला पाठवली जात नाहीत.

- Windows कार्ये: `%AppData%\BUtil Backup Tasks`
- Linux कार्ये: `~/.config/BUtil Backup Tasks`
- Windows सेटिंग्ज (थीम आणि परवाना किंवा गोपनीयतेसाठी शेवटी निवडलेली भाषा यासह): `%AppData%\BUtil\Settings\v1`
- Linux सेटिंग्ज: `~/.config/BUtil/Settings/v1`
- Windows कार्य स्थिती: `%AppData%\BUtil\States`
- Linux कार्य स्थिती: `~/.config/BUtil/States`
- Windows माध्यम आयात स्थिती: `%AppData%\BUtil Backup Tasks - States`
- Linux माध्यम आयात स्थिती: `~/.config/BUtil Backup Tasks - States`

### तुम्ही निवडलेल्या फाइल्स

बॅकअप, समक्रमण, पुनर्संचय आणि आयात तुम्ही निवडलेले फोल्डर वाचतात आणि लिहितात. त्या फाइल्स या संगणकावर किंवा तुम्ही सेट केलेल्या साठवणीवर राहतात. अ‍ॅप त्या विकासकाला पाठवत नाही.

### नोंदी

निदान नोंदी फक्त या संगणकावर लिहिल्या जातात:

- Windows: `%LocalAppData%\BUtil\logs\v4`
- Linux: `~/.local/share/BUtil/logs/v4`

त्या फाइल्स कुठेही पाठवल्या जात नाहीत.

तुमचा डेटा साठवण्यासाठी विकासकाचा सर्व्हर वापरला जात नाही.

## नेटवर्क वापर

### तुम्ही सेट केलेली गंतव्ये

कार्य चालू असताना अ‍ॅप फक्त तुम्ही ठरवलेल्या ठिकाणी जोडते. ते स्थानिक फोल्डर किंवा तुम्ही टाकलेला सर्व्हर असू शकतो: FTP, FTPS, SFTP, WebDAV, SMB, NFS, S3-सुसंगत साठवण किंवा Azure Blob Storage. फाइल नावे, सामग्री आणि तुम्ही टाकलेली ओळखपत्रे कार्य चालण्यासाठी त्या सर्व्हरला पाठवली जातात. प्रत्येक सेवेचे स्वतःचे गोपनीयता धोरण आहे. विकासकाला हा ट्रॅफिक मिळत नाही.

BUtil Server या संगणकावर ऐकू शकतो जेणेकरून तुम्ही सेट केलेला BUtil क्लायंट फाइल्स पाठवू शकेल. तो ट्रॅफिक तुम्ही सेट केलेल्या संगणकांमध्ये राहतो.

## वेळापत्रक

Windows वर तुम्ही साइन-इन वेळी किंवा साप्ताहिक वेळापत्रकानुसार कार्य चालवू शकता. अ‍ॅप ते Windows Task Scheduler मध्ये `BUtil` ने सुरू होणाऱ्या नावाने नोंदवते. यामुळे फक्त हे अ‍ॅप तुमच्या संगणकावर सुरू होते.
