O BUtil faz cópias de segurança, sincroniza e restaura ficheiros. As cópias incrementais guardam apenas o que mudou. A deduplicação mantém uma única cópia quando o mesmo ficheiro aparece mais do que uma vez.

Para onde vão os ficheiros

Envie as cópias para uma pasta, um NAS (SMB/CIFS) ou para WebDAV, armazenamento compatível com S3, NFS, Azure Blob, SFTP ou FTPS.

- Sincronize uma pasta através de armazenamento que controla e mantenha versões anteriores quando os ficheiros mudarem.
- Importe imagens, vídeo e áudio de um cartão SD ou de uma câmara.
- Execute tarefas numa agenda, inclusive a partir da consola.

As palavras-passe que guarda são cifradas no dispositivo. Não há conta, nem publicidade, nem telemetria.

O BUtil é de código aberto. O código próprio é dedicado ao domínio público. Os componentes de terceiros mantêm as próprias licenças.
