증분 백업은 마지막 실행 이후 바뀐 것만 저장합니다.
중복 제거는 같은 파일이 여러 번 나와도 사본을 하나만 남깁니다.
이미 만든 백업에서 파일을 복원합니다.
로컬 폴더, WebDAV, S3 호환 저장소 또는 NFS에 백업합니다.
NAS(SMB/CIFS), Azure Blob, SFTP 또는 FTPS에 백업합니다.
직접 관리하는 저장소를 통해 컴퓨터 사이에서 폴더를 동기화합니다.
동기화된 파일이 바뀌면 이전 버전을 남깁니다.
SD 카드나 카메라에서 사진, 동영상, 오디오를 가져옵니다.
같은 Wi-Fi의 휴대폰에서 사진과 동영상을 가져옵니다.
가져온 파일 이름을 선택한 템플릿으로 짓습니다.
로그인할 때 또는 주간 계획으로 백업을 예약합니다.
같은 작업을 콘솔에서, 예약을 포함해 실행합니다.
작업을 자동화하도록 콘솔 명령을 복사합니다.
어떤 작업이 예약되었는지, 마지막 실행이 어떻게 끝났는지 봅니다.
저장한 암호는 이 컴퓨터에서 암호화됩니다.
작업 후 PC를 켜 둔 채 두거나, 로그아웃, 다시 시작, 종료할 수 있습니다.
오픈 소스. 계정, 광고, 원격 측정이 없습니다.
폴더를 업로드하고, 이미 저장된 파일은 건너뜁니다.
