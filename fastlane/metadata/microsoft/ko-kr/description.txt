BUtil은 이 PC에서 파일을 백업하고, 동기화하고, 복원합니다. 증분 백업은 바뀐 부분만 저장합니다. 중복 제거는 같은 파일이 여러 번 나와도 사본을 하나만 남깁니다.

백업은 이 PC의 폴더, NAS(SMB/CIFS), 또는 WebDAV, S3 호환 저장소, NFS, Azure Blob, SFTP, FTPS로 보낼 수 있습니다.

직접 관리하는 저장소를 통해 폴더를 동기화하고, 파일이 바뀌면 이전 버전을 남깁니다. SD 카드, 카메라, 또는 같은 Wi-Fi의 휴대폰에서 사진, 동영상, 오디오를 가져옵니다.

같은 작업은 콘솔에서도 실행되며, 예약도 됩니다. 저장한 암호는 이 컴퓨터에서 암호화됩니다. 계정, 광고, 원격 측정이 없습니다.

BUtil은 오픈 소스입니다. 자체 코드는 퍼블릭 도메인입니다. 타사 구성 요소는 각자 라이선스를 유지합니다.
